# 任务
为文末 `<material>` 中的英语语篇一次性命制**两个独立版本**的高考风格阅读理解选择题（版本 A、版本 B，各 4 题，每题 A/B/C/D 四个选项），供教师对比鉴别、择优采用或交叉拼合。使用者是中学英语教师，题目用于课堂练习或模考命题——同一语篇的设问方案不唯一，两个版本能帮教师看清不同设问路径的取舍。

# 命题规则（两个版本共同遵守）
**镜像映射**：设问分布与语篇结构对应——先分析语篇的功能框架（引入 → 展开 → 转折/发现 → 收束），再让题目落在这些关键功能节点上：开头的问题起因/主题引入、段落间的关键转折、研究的核心发现、结尾的趋势判断或态度立场。不问孤立细节（"谁、何时、多少"式的数字定位题）。

**难度梯度**：每版 4 题难度递进，从事实理解逐步升级到语篇功能、态度情感、因果逻辑层面；最后一题为主旨大意或最佳标题题。

**正确选项**：
- 必须基于文本证据合理推断，不能是原文某句话的简单重复或同义词机械替换
- 用上位概念概括原文信息（如把 genetic diversity 概括为 valuable genetic resources）
- 关键词精准外显文本逻辑（如用 indirectly 揭示间接因果链）

**干扰项**："形合意不合"——像对但确实错。每题的干扰项从以下策略中选用：
- 表面词汇陷阱：重现原文高频词，但句意与上下文逻辑脱节
- 偏离核心主题：符合常识但与该段的具体主题无关
- 逻辑冲突：与文章主旨或作者态度相悖
- 局部细节过度延伸：抓住文中微小细节做过度推断

**选项语言**：同题四个选项简洁、结构相近、长度大致相等，不靠长度暴露答案。

# 两个版本的差异化要求
两版不是同一套题的措辞微调，必须在命题路径上真正不同：
- **版本 A（标准化取向）**：信息覆盖面广、多点取样，题目分布均匀覆盖各段，侧重实证细节的因果与推断，答案唯一性强、可测量性好
- **版本 B（综合思辨取向）**：设问更集中于语篇的核心矛盾或深层意义，侧重态度立场、写作意图、信息价值的抽象概括，综合性强

同一个文本位置两版都设题时，设问角度必须不同。

# 输出格式
Markdown，依次输出：
1. **语篇结构速览**（中文，3-5 行）：功能框架与可设题的关键节点
2. **版本 A**：4 题（英文，编号 1-4）+ 逐题中文说明（答案、文本证据引用原文、干扰项用了什么策略、为什么错；每题不超过 3 行）
3. **版本 B**：格式同版本 A
4. **鉴别指引**（中文表格）：逐一对比两版对应题目——考查能力、难度、区分度预判、各自的强项与风险，最后给出择优或拼合建议

# 例外处理
- `<material>` 为空或不是英语语篇：不要命题，说明需要粘贴一篇英语语篇，不要输出其他内容。
- 语篇过短（不足 150 词）：每版减为 2-3 题并注明。
- 材料中教师指定了题量或侧重：优先遵循教师要求，但仍保持两版差异化。

# 命题语篇
<material>
{{user_input}}
</material>

为以上语篇命制版本 A、版本 B 两套差异化的阅读理解题，并附鉴别指引。

# 排版（视觉可读性）
输出是给人读的 Markdown，渲染后的视觉可读性优先：并列信息用表格，层级关系用列表，结论与关键信息用加粗，原文引用用引用块或斜体，说明性长段落拆成短句、短段。输出中引用的原文、例句、题目与学生习作原样照录（包括其中的错误），润色、缩写、纠错只做任务明确要求的事；上文已定死的标题、条目、题号与固定模板不变，本节只约束其余行文。
