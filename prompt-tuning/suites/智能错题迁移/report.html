P2 / 10 · 方法

怎么测的三类证据，两个独立仪器，全部可复跑

证据类型做法
决策模型评分把"这道题好不好"拆成 7–14 个窄二值问题（Jev 的 noul/choice/score），逐题逐选项判定；每版 ~110 题
单维度盲评两份匿名输出，只就一个方面问"哪份更好"；同一对正反顺序各问一次，只认一致票
机械检测不依赖模型，直接统计：词族角色、选项长度、字母/槽位分布、方法论泄漏、结构完整性

两个仪器（互相校验）

仪器位置类型用量
respan/span-01-liteOpenRouter仅 noul免费不限量
typesafe/jevCommand Codenoul / choice / score$0.04per M 输入

统计口径

  • 问题率：判定阈值下的不合格比例（反向指标取 >0.5 为不合格）
  • Wilson 95% CI：比例型指标的置信区间，报告里随 n 一并给出
  • 符号检验：盲评胜负是否为偶然（p 值双侧）
  • 顺序对调：位置偏差控制；两次矛盾记为无效票
  • 题级配对相关（Pearson r）：证明两仪器的读数可靠，而不是噪声

为什么 LLM 盲评测不出邪修改善？
评审模型会认真读题，不会用"见了 repeat 就排除"这种策略；而这类规律恰恰只对真实弱学生有效。所以邪修治理的收益只体现在机械检测上（P6 页），LLM 盲评自然显示为"打平"。

局限（如实列出）

  • 仪器绝对水平不一致：如"凑数项"一项两仪器相差 14 倍，属措辞读数差异
  • 样本量：每版 ~110 题，问题率型指标 CI 约 ±5–10 个百分点
  • 盲评顺序矛盾率：版本接近时高达 10–79%，此时结论只能记"打平"
  • 决策模型不擅长多步推理：涉及推理的判定已拆成窄问题，但仍有个别噪声
  • 跨轮词库复用：无状态 prompt 记不住上一轮出过什么（做过 cool/reserved 的复现）
  • 残留 1/30 文件有词族角色固化（P6）
