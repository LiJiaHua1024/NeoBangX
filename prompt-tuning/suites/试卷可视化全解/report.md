# 试卷可视化全解 · Prompt 调优报告（v0 → v3）

调优对象：`prompts/试卷可视化全解.md`（生产版 = v0，16.8KB）。
调优方式：**把「智能错题迁移」已验证的 v17 迁移题机制整段移植过来**，不改输出契约、不重写讲解部分。
全部数字来自 `runs/试卷可视化全解/work/` 的原始 JSON，用 `scripts/vp_report.py` 现算。

---

## 一、结论摘要

| 指标 | v0（生产版） | v3（本次成果） | 判定 |
|---|---|---|---|
| **迁移题换皮率**（决策模型，n=42 块） | 69% | 21% / 31%（两轮） | **真改善**，远超噪声 |
| **迁移题迷惑性不足率**（n=37 选择题块） | 92% | 60% / 68% | **真改善** |
| **机械问题总数**（9 文件 / 42 迁移块） | 25 | 3 / 5 | **真改善** |
| 七选五选项池失真 | 5/5（100%） | 0/5、0/5 | **已修** |
| 迁移答案字母全落同一字母 | 2 个案例（4/4 A、6/8 B） | 0 | **已修** |
| 语法填空迁移多空漂移（考点漂移） | 0 | 0（v2 复现轮曾 5/5，已加精确定义） | 已修 |
| 迁移语篇 <80 词 | 12 处（29%） | 1 处、4 处 | 大幅减少 |
| 盲评：迁移真实性 | — | **5 : 0 全胜**（两轮独立复现，p=0.062） | **真改善** |
| 盲评：范式质量 | — | 4 : 3（v1 时曾是 1 : 3，措辞修补后追平） | 已止血 |
| 盲评：整体投影可用性 | — | 1 : 3（v1 时 1 : 4） | ⚠️ **仍未解决的代价** |
| 范式可套用性（原题四维之一） | 0%（0/34） | 12% / 15% | ⚠️ **真实回归**（合并 p≈0.01） |
| 正确项"最长项"线索 | 50%（n=30） | 50% / 41% | 未改善（噪声内） |
| 证据跨句拼接 | 1 处 | 0（v2 轮曾出现 1–2 处） | 未根治，属自查不可靠类 |

一句话：**用户抱怨的"迁移是假的、选项太明显"这次被真正修掉了**（换皮 69%→21%、迷惑性 92%→60%、机械检查 25→3），代价是提示词从 16.8KB 涨到 26.6KB，并带来两处可见的副作用——**范式可套用性下降约 13 个百分点**、**整体观感仍偏向原版**。这两条是下一步该处理的事，不是可以糊过去的。

## 二、评测基础设施（本次新建）

生产 prompt 的输出是 `@@TAG@@` 行协议 + 流式逐题渲染，与"错题迁移"的四固定标题完全不同，所以仪器是新写的：

| 仪器 | 脚本 | 问什么 | 规模 |
|---|---|---|---|
| 机械检查 | `vp_check.py` + `vp_parse.py` | 协议合规 22 类、照录保真、迁移质量、范式泄题 | 秒级、免费 |
| 决策模型评分 | `vp_scorer.py` | 15 个窄判定（原题四维 6 项 + 迁移块分型 4–6 项） | 456 次判定 |
| 单维度盲评 | `vp_aspect.py` | 一次只问一个方面，正反双顺序，只认一致票 | 70 组 = 140 次 |
| 汇总 | `vp_report.py` | 从原始 JSON 现算，附 Wilson 区间与符号检验 | 秒级 |

案例集 = 7 份**真题切片**（2022 年全国甲卷，含参考答案），覆盖该 prompt 的全部结构分支：

| 案例 | 覆盖点 |
|---|---|
`c1_reading_b` | 材料含听力 → 测"跳过听力 + 题号不重排（首题 24）"+ 同篇 4 题共用一份语篇定义 |
`c2_reading_c` | 词义猜测/推断/态度/主旨四类设问 |
`c3_cloze7` | 七选五 5 空 7 共享选项池（跨空排除） |
`c4_cloze_blank` | 完形多空同一语篇 |
`c5_grammar` | 语法填空无选项（`QTYPE=blank`、禁编 A/B/C/D） |
`c6_writing` | 写作题分支（无迁移、三件套） |
`c7_reading_a_nokey` | 材料未附答案 → NOTICE 诚实声明 |

**噪声底（本次最重要的方法学数字）**：用同一份 prompt（v3）重跑一轮，两轮之间
换皮 21% vs 31%、迷惑性 60% vs 68%、机械问题 3 vs 5。即 **n=42 时，±10 个百分点以内的差异不能当结论**。
下文所有"改善"都以此为尺。

## 三、v0 基线实测：问题全在迁移题

机械检查 9 份 / 42 迁移块共 **25 项问题**：迁移语篇词数不足 12、选项池失真 5、答案字母集中 4、长度线索 2、绝对化线索 1、证据拼接 1。

决策模型（n=42）：**迁移块"换皮"69%、"迷惑性不足"92%**；
而**原题四维六项问题率全部为 0%**（答案唯一性、证据充分性、易错点具体性与独立性、范式可套用性、推理一致性）。

也就是说：**这份 prompt 的讲解部分质量很高，短板就是迁移题**——与"错题迁移"当初的病灶完全一致。所以修复直接沿用已被验证的机制，而不是重新发明。

两条具体的实锤（可直接回原文核对）：

- `[c5] Q61` 语法填空：原题 `as a first step 61 (journey) the Belt and Road route`，迁移写成
  `As a first step ___ (test) her idea` —— **框句照抄，只换括号里的词**。
- `[c7] Q22` 证据：Glee Club 段的两句被拼成一条证据，**跳过中间那句**
  （`It is hard to name a comedy star who hasn't been on the stage here.`）——教师按证据回原文找不到连续段落。

## 四、移植映射：v17 的机制 → 本 prompt 的形态

| 「智能错题迁移」v17 已验证的机制 | 移植后的形态 |
|---|---|
| 出题流程「先写方法论并锁定」 | 先写 `PATTERN_NAME`/`PATTERN_STEPS` 再出题；范式不得迁就某题改成"看到某类词就选某项"的类别映射 |
| 「方法论要写到第一步看什么、第二步排什么」的颗粒度 | **范式必须写成不依赖原题具体内容的流程**（v1 实测：范式写成"先读小标题：Chopstick Rules"就套不上迁移题） |
| 学生默认"错误直觉"清单，干扰项从清单取材 | 原样移植（长选项更对／绝对化必错／原词复现是答案／排除最荒谬的剩中间） |
| 干扰项套路分配表（五种错法轮换、同种 ≤2 次） | 原样移植，带"迁移块总数 ≥5 时"守卫 |
| 命题骨架分配表（≥3 种骨架、三拍骨架 ≤2 次、无解释反推题、多段落语篇） | 原样移植 |
| **原题指纹禁令**（实词/场景/句式/选项四类） | 原样移植，并补一条本 prompt 特有的辨析：**考点语法结构要保真，但框句必须重新设计** |
| 远迁移"去路标" | 原样移植（隐去转折词/时间状语/本人引语，改写成需推理的形式） |
| 半对干扰项、正确项与证据隔一步推理、定义句不算证据、反证句只可否决 | 原样移植 |
| 双通道验证（凭应试直觉必须错或犹豫） | 原样移植 |
| 可归纳性审查（防"邪修"）：考点词隐性替换＋角色双向、正确项原型轮换、字母/位置机会均等、选项长度均衡 | 原样移植（角色双向按"同一份输出内的迁移题之间"执行） |
| 答案多样性（语法填空主动侧 ≥3 题） | 原样移植 |
| 题量守卫（"至少 N 题"在极小样本下要可定义） | 新增定义：迁移块总数＝题数 × `{{transfer_count}}`，配额一律带"≥5 时" |
| 方法论泄题禁令 | 移植为「范式不泄题」＋新增机械检查 `pattern_leak` |
| —（v17 不存在此类问题） | 本 prompt 特有、v17 没有的两条：**选项池形式必须与原题一致**、**EVIDENCE 必须是连续原文** |

## 五、逐版数据

三轮及以上版本 + 两个复现轮，同口径（9 文件 / 35 题 / 42 迁移块 / 76 判定单元）：

| 版本 | 机械问题 | 换皮率 | 迷惑性不足率 | 机制同源失败 | 同型失败 | 填空考点漂移 | 范式可套用失败 |
|---|---|---|---|---|---|---|---|
| v0（生产版） | 25 | 69% | 92% | 0% | 10% | 0% | **0%** |
| v1（移植版） | 3 | 24% | 65% | 5% | 0% | 0% | **18%** |
| v2（+指纹/范式通用性） | 11 | 24% | 65% | 5% | 2% | 0% | 9% |
| v2 复现轮 | 13 | 26% | 62% | 10% | 2% | **100%** | 21% |
| **v3（+两处精确定义）** | **3** | **21%** | **60%** | 2% | 5% | 0% | 12% |
| v3 复现轮 | 5 | 31% | 68% | 7% | 0% | 0% | 15% |

读法（以 ±10pt 噪声底为准）：

1. **换皮与迷惑性的改善是真的**：69%→(21%,31%)、92%→(60%,68%)，两轮都远超噪声。
2. **v1/v2/v3 之间在换皮、迷惑性上没有可辨识差异**——差别集中在范式与格式的边界情形，所以选 v3 靠的是下面两条，不是靠这两项。
3. **v3 修掉了两处边界漂移**（都是复现轮暴露的）：
   - `v2 复现轮` 的七选五迁移把选项池从 7 项缩成 5 项 → 精确定义为"与原题项数相同"；
   - `v2 复现轮` 的语法填空迁移把一道题挖成 3 个空（第 3 空考的是定语从句 "who"，考点漂了，`transfer_blank_target` 100% 失败）→ 精确定义为"blank 类型只挖一个空；多空共享池规则只适用于原题本身带共享池的题"。v3 两轮此项均归零。
4. **范式可套用性的下降是真实代价**：v0 = 0/34，v1–v3 五轮合并 25/170 ≈ 14.7%（单侧 p≈0.005）。
   机制清楚：迁移题被推得更远（换域、去路标、还带共享池），一道三步范式就**不再机械等价于答案**。
   也就是说 v0 那个漂亮的"范式 100% 可套用"，有相当一部分来自**迁移题离原题太近**（即换皮）。
   这是设计上的取舍，不是可以两边都要的东西。

### 盲评（单维度、正反双顺序、只认一致票）

| 方面 | v1 vs v0 | v3 vs v0 |
|---|---|---|
| 迁移真实性 | **5 : 0**（100%，p=0.062） | **5 : 0**（100%，p=0.062） |
| 迷惑性 | 4 : 2（67%） | 3 : 2（60%） |
| 范式质量 | 1 : 3（25%） | 4 : 3（57%） |
| 照录与格式 | 0 : 2（含 3 平） | 1 : 1（含 2 平） |
| 整体可用性 | 1 : 4（20%） | 1 : 3（25%） |

两轮的"迁移真实性"独立复现 5:0，是本次最稳的一条结论。
"范式质量"从 1:3 回到 4:3，说明 v2/v3 对范式的措辞修补起了作用。
"整体可用性"两轮都偏向 v0（合并 7:2，n=9，p≈0.18，未达显著但方向一致）。

## 六、两台仪器的一致与分歧（必须如实说明）

**一致**：迁移真实性（评分器：机制同源失败 0–10%、换皮 69%→21%；盲评 5:0）、范式质量（评分器：0%→9–21%；盲评：1:3 偏 v0）。

**分歧**：**迷惑性**。评分器说大幅改善（92%→60%），盲评说无从区分（3:2，含 1 平 1 矛盾）。
分歧的原因是可解释的：评分器逐块问"半懂学生会不会被这些干扰项钓到"，盲评是通读整份课件的整体印象，
而**整份课件里还有大量照录的原题讲解部分**（四维质量两版都很好），会把整体印象拉平。
对外汇报时，迷惑性这条应引用评分器 **并注明盲评未复现**。

另有一处仪器自身的修正：v1 第一版评分器对**语法填空题**的迁移问"错误选项有没有吸引力"——该题型没有选项，
问题本身不成立（v0/v1 那 5 个单元的该项数据因此作废）。现已改成分型提问（选择题问迷惑性、填空题问答案唯一与考点单一），
并用 `SCHEMA` 后缀隔离旧缓存。

## 七、剩余问题与建议

1. **整体观感是唯一没赢的方面**（合并 7:2 偏向 v0）。最可能的原因是**体积**：16.8KB → 26.6KB，
   附加的配额表与可归纳性审查让输出更"按表填空"，通读者会觉得不如原版干净。
   建议：**不要再往这份 prompt 里加规则**；若要继续提升，应按 v17 时得出的结论，把细则外移到生成后门禁。
2. **三处"自查不可靠"的残留**（属同一类，实测在两版里都反复出现）：
   - 迁移语篇不足 80 词：v0 12 处 → v3 1–4 处（大幅减少但未归零）；
   - 正确项是最长项：v0 50% → v3 50%/41%（**没有改善**，"正确项写得更完整"是极强的默认倾向）；
   - EVIDENCE 跨句拼接：v0 1 处、v3 0 处，但 v2 轮次出现过 1–2 处（**未根治**）。
   这三条都适合做成**生成后门禁**（`vp_check.py` 已经能逐条检出，可直接接后端做重生成或修标签），
   而不是继续在 prompt 里加"请你数一数"这类自查——这条经验与"错题迁移"那次一致。
3. **整卷一次性生成仍未验证**：30+ 题的输出量超出单次调用预算（"基本一次跑不完"是已知现象）。
   本次全部用切片输入，因此 `@@END_Q@@` 的"截断也不丢已完成题"语义未被覆盖，属未测区域。
4. **切片输入的补号无锚点**：`c6_writing` 只有写作一题、卷面未印题号时，模型补为 1。整卷输入才有顺延锚点，
   仅记录，不计为缺陷。
5. **体积红线**：《Prompt Engineering Guide》建议把 prompt 控制在 8–10KB 量级。本 prompt 即使 v0 也有 16.8KB，
   其中约 8KB 是输出契约（`@@TAG@@` 协议 + 示例），**是前端解析器的接口，不能删**。
   若将来要瘦身，唯一正确的方向是**把契约从 prompt 移到服务端格式化层**（模型输出结构化字段，由后端拼标签），
   那是工程改动，不是调 prompt。

## 八、复现

```bash
cd prompt-tuning
# 机械检查（秒级、免费）
uv run python scripts/vp_check.py --round v3 --suite 试卷可视化全解
# 决策模型评分（快、便宜）
uv run python scripts/vp_scorer.py --rounds v0,v1,v2,v3 --config jev_config.json --suite 试卷可视化全解
# 单维度盲评（正反双顺序）
uv run python scripts/vp_aspect.py --round-a v3 --round-b v0 --aspects transfer,deception,pattern,fidelity,overall \
  --config jev_config.json --suite 试卷可视化全解
# 汇总为报告表（含 Wilson 区间与符号检验）
uv run python scripts/vp_report.py --rounds v0,v1,v2,v2_r2,v3,v3_r2 --pairs v1-vs-v0,v3-vs-v0 --suite 试卷可视化全解

# 重新生成某一版（第 1 条为档位 1 全案例，第 2 条是能触发 ≥5 配额表的档位 2）
uv run python scripts/gen.py --round v3 --prompt suites/试卷可视化全解/prompt/v3.md --counts 1 --suite 试卷可视化全解
uv run python scripts/gen.py --round v3 --prompt suites/试卷可视化全解/prompt/v3.md --counts 2 \
  --cases c1_reading_b,c2_reading_c --suite 试卷可视化全解
```
