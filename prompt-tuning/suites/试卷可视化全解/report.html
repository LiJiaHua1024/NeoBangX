P8 / 10 · 边界

复现轮抓到的两处边界漂移只有一个样本时会被误判成"v2 比 v1 差"；加一轮复现后定位到具体规则歧义

漂移实际发生根因v3 修法
七选五迁移把选项池从 7 项缩成 5 项 v2 轮 5/5 块；v2 复现轮 0/5 "同规模共享选项池"的"同规模"有歧义 精确化为"与原题项数相同，多余项数也一致"；v3 两轮均为 0
语法填空迁移挖成 3 个空 v2 复现轮 5/5 块（第 3 空考的是定语从句 who，考点漂了） "共享池要保真"被过度泛化到无选项题型 精确化为"blank 只挖一个空；多空共享池规则只适用于原题本身带共享池的题"；v3 两轮均为 0
两次都是"规则歧义"
不是"规则不够多"。v3 只做了两处精确化，没有新增任何规则——这也解释了为什么 v3 的机械问题回到 3–5 项而没有继续恶化。
耀斑信号的处理
当 v2 看起来"修好迁移、坏了格式"时，第一反应不是继续加规则，而是先量噪声底、再做复现轮，最后才动手修。避免了规则通胀。

另外修掉一个仪器缺陷：评分器最初对语法填空题的迁移问"错误选项有没有吸引力"—— 该题型根本没有选项，问题本身不成立（v0/v1 那 5 个单元的该项数据因此作废）。 现改为分型提问并用 SCHEMA 后缀隔离旧缓存。

P10 / 10 · 结语

一句话总结

你抱怨的两件事——迁移是假的、选项太明显——这次是真的修掉了： 换皮率 69% → 21%，迷惑性不足率 92% → 60%，机械问题 25 → 3， 迁移真实性在单维度盲评里两轮独立拿到 5:0。

做法不是重新造一套，而是把「智能错题迁移」已经验证过的机制逐条搬过来（先写范式、两张分配表、指纹禁令、去路标、双通道、可归纳性审查）， 再补两条这份 prompt 特有的（选项池形式保真、证据必须连续）。

代价也如实说：范式可套用性掉了约 13 个百分点（迁移变远的必然结果，p≈0.01）， 整体观感仍然偏向原版（2:7，未显著），这三处"自查不可靠"的残留建议交给后端门禁而不是继续加规则。
