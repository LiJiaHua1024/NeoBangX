## 一、最终交付

**`prompts/智能错题迁移.md` = v11 精简版（7.4KB，约 2400 字）**，由 v10 规则版（18.7KB）蒸馏而来。蒸馏依据是一次同条件对比实验（见第四节）：两版质量打平（盲评 A/B 4:3），精简版在结构稳定性与盲测一致性上反而更好，且符合"防规则通胀、注意力预算"的方向。

保留的是被 11 轮迭代证明**结构性有效**的规则：出题流程顺序（方法论先写锁定）、双通道验证、迁移三档与档位分配、原题指纹禁令、干扰项钓鱼路径、难度红线、输出契约。

被移除的细则（答案词族对冲、命题骨架分配表、语法同形细则、原型轮换、删句测试、顺序词禁令等）全部记录在**失败样例库**（`work/failure_library.md`）与第六节附录中——它们是未来 verifier agent 的现成检查清单，本次按约定不做 harness engineering。

## 二、两个原始投诉的验证结论

### 投诉① "迁移"名不副实（同语境换皮、设错点雷同）——已解决

基线实证（v0）：c1 十题同一叙事模板换名词（近迁移位与原题逐句对应）；c2 复用原题选项组；c4 复用原七选五语篇；迁移题与原题最长公共子串最高 62 字符。
终版实测：重叠 ≤15 字符区间（除错因必需词对）；盲评确认"题与原题、题与题之间真不同"；c4 出现真七选五共享选项池、c2 出现语篇完形、语法类恢复填空为主。

### 投诉② "对的太对、错的太错"——显著改善，目标人群有效

基线实证：正确答案位置连坐、干扰项"regret/plan to close"一眼假、强模型盲测零迟疑全对、学霸 10 秒秒杀。
终版实测：每个干扰项有具体钓鱼路径并在解析还原；双通道验证保证"凭直觉必错或犹豫"；组长评审 c1 迷惑性 6→8.5（"骗中等偏上学生真有胜算"）；高考生实测确认陷阱对目标学生（做错原题的中段生）有效（如 c3"见介词选 -ed"直觉在正确项上翻车）。

## 四、终局对比实验：规则版 v10 vs 精简版 v11

同条件（6 案例 × 档位 {1,3,5,10}，同一生成模型、同一评审池）：

| 指标 | v10 规则版（18.7KB） | v11 精简版（7.4KB） |
|---|---|---|
| 结构全绿 | 22/24 | **24/24** |
| 方法论泄漏 | 0 | 0 |
| 盲测不一致 | 4/109 | **2/109** |
| 盲评 A/B overall | **4 胜** | **3 胜**（0 平） |

A/B 逐组裁决显示两版各有所长：v10 赢在 c1（命题骨架分配表带来更丰富的结构变化——这是重规则唯一明显的增量），v11 赢在 c2（迁移真实性）、c6（规避 had done 双解）。结论：**质量打平，精简版胜出**——结构更稳、成本更低、符合架构方向。v10 的骨架分配表经验已记录，供 verifier agent 阶段使用。

GLM subagent 独立评审（3 轮深审 + 2 次实测）给出的版本轨迹：v4 73/75/67（"解决了题对不对，没解决像不像人出的"）→ v6 84/78/75（"跨过不能用线"）→ v7 86/78/76（"下一步的对手是对新规则的过度服从"）——这句话正是停止加规则、转入 verifier 架构的实证依据。

## 五、各档位（1-10）验证

- 档位覆盖：全部 1-10 档在 v4 系全档位扫描（v4b，36 份）中验证通过；终版 v11 在 {1,3,5,10} 四档 × 6 案例验证。
- 档位相关规则：1 题直接远迁移且禁止多空凑数；≥5 题触发格式保真（七选五/完形语篇、绝对化反转、部分正确干扰项）；≥3 题梯度分配。各档位结构检查全绿。
- 档位间的质量差异主要来自题量：5-10 题时干扰项套路与话题的分散压力大（已由禁令缓解），1-2 题质量最稳。

## 六、移出 prompt 的细则清单（未来 verifier agent 的检查清单）

以下规则在迭代中曾入 prompt，最终为控制规则通胀而移出，全部有失败样例支撑（详见 `work/failure_library.md`）。verifier agent 阶段可直接据此构建审查项：

1. 命题骨架分配：≥3 种骨架；"旧话→外力→本人解释"三拍骨架 ≤2 次；≥2 题无本人解释引语；≥1 题多段落长文
2. 干扰项错法架构轮换：引语复现/过度夸大/编造动机/半对项/真而无关，五种各≥1 次；同套路 ≤2 次
3. 答案词族对冲：辨析词对在 ≥60% 题的选项在场；每个成员至少担任一次正确项与一次最强干扰项
4. 语法同形：四选项都必须能无碍填入空格（除非考形式辨析）
5. 正确项原型轮换：带限定语的折中项 ≤ 一半
6. 删句测试：正确项删除后语篇逻辑应断裂
7. 顺序词不作免费信号；指代方式轮换（回指/复现/转述）
8. 绝对化反转（≥5 题 1 题）；部分正确干扰项（≥5 题 2 题需权衡）
9. 证据隔步：推断类线索 ≥2 处；定义句不算证据；反证句只准否决干扰项
10. 功能唯一性（插入句类）：空白功能先写一句话，四选项唯一满足
11. 选项组照搬检测、克隆干扰项检测、目标词组内不重复（多空语篇豁免）
12. 高频题材限额（开店/社团/合唱团/图书馆等全套 ≤1 次）
13. 答案字母不连坐（≤2 连续）且不成周期（如 BDAC-BDAC）
14. 解析否决理由与题面事实一致性自检

## 七、遗留问题与建议

1. **迷惑性天花板**：对 125 分强学生，生成题尚不能稳定达到"incandescent 级"真题迷惑量级（三版实测仅 2-3 题达标）。这是单错因批量出题的固有限制；对目标人群（做错原题的中段生）陷阱有效。
2. **跨轮多样性**：无状态 prompt 记不住上一轮出过什么（cool/reserved/dry、equipped 等跨轮复用被实测抓到）。彻底解法在 harness 阶段：前端把上一批题材摘要随 user_input 传入，或 verifier 抽查。
3. **生产环境 max_tokens（重要）**：`config.py` 默认 4096。v4.1-flash 是推理模型，reasoning tokens 计入 max_tokens——测试中 8192 预算下 17/24 任务正文 0 字（全部烧在 reasoning）。**该工具生产配置建议 ≥32768**，否则上线即空输出。
4. **方法论-题干泄漏门禁**：`leak_check.py` 已交付（3-gram 重合 + 原题豁免），v9 起 prompt 层面稳定输出 0 泄漏；建议后端集成该脚本作为质量门禁（生成后自动查重，超阈值打回）。
5. **残余双解**：约 1-2 题/百题的动词语义两可（如 rehearsed vs repeat 类），属命题固有灰区，verifier 阶段可加"时间/条件唯一性"审查。
