# 字体来源与许可

这些字体文件从上游 `dsh-claude-style@1e7acc5be061be06cd3850962abd3ad103259bfd` 的
`packages/assets/src/fonts/` 复制，用于 `/agent` 的界面复刻。

| 文件 | 字体 | 许可 / 说明 |
| --- | --- | --- |
| `AnthropicSansWebText.ttf` | Anthropic Sans Web Text | Anthropic 的字体，上游明确说明**不适用 MIT、仅供个人使用**，不随 npm 包发布。本项目只作个人界面复刻；商业分发前必须替换。 |
| `AnthropicSerifWebText.ttf` | Anthropic Serif Web Text | 同上 |
| `AnthropicMonoWeb.ttf` | Anthropic Mono Web | 同上 |
| `InterVariable.woff2` | Inter | SIL Open Font License 1.1 |
| `NotoSerifVariable.woff2` | Noto Serif | SIL Open Font License 1.1 |
| `JetBrainsMonoVariable.ttf` / `JetBrainsMonoItalicVariable.ttf` | JetBrains Mono | SIL Open Font License 1.1 |
| `OFL.txt` | — | Inter / Noto Serif / JetBrains Mono 的 OFL 许可证原文 |
