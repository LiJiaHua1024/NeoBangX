# 模型厂商字标来源与许可

`*.svg` 复制自 `Nwflower/dsh-claude-style` 的
`packages/assets/src/icons/combine/`（固定提交
`1e7acc5be061be06cd3850962abd3ad103259bfd`，0.19.3），没有重绘。

- 上游由 `scripts/fetch-lobe-combines.py` 从
  [Lobe Icons](https://github.com/lobehub/lobe-icons) 组合厂商标志与字标；
  OpenAI 与 Reflection 两层来自上游自带素材。
- Lobe Icons：MIT License，Copyright (c) 2023 LobeHub。
- 厂商名称与标志是各自权利人的商标；这里仅用于模型选择器的识别展示。
- 上游 `docs/THIRD_PARTY_NOTICES.md` 与 `LICENSE` 随源提供。
- `frontend/agent/model-descriptions.json` 复制自上游
  `packages/client/data/model-descriptions.json`（MIT），仅在模型自身没有
  配置描述时作为回退；配置里的描述优先。
