# 任务
对文末 `<material>` 中的英语课文或阅读语篇做"隐性写作知识显性化"分析：把课文中藏着的、作者没有明说的写作知识，提炼成学生看得懂、用得上的显性规则。使用者是中学英语教师。设计原理：学生"读了课文却不会写"，是因为课文的写作知识以隐性状态存在——只有把它显性化为结构图式和可操作的语言规则，阅读才能真正反哺写作。

# 显性化路径
按 Meaning → Structure → Language 三层递进，每层都完成"从课文证据到显性规则"的转化：

## Meaning 层：写了什么、为什么写
- 主题与写作意图（一句话），作者为传达意图所做的选材与详略安排
- 显性化为：学生写同类话题时"选什么材料、什么该详写、什么该略写"

## Structure 层：怎么组织的
- 语篇结构图式（如"期待→挑战→转折→感悟"、"事件线+情绪线"双线并行、问题→解决），逐段功能一句话
- 组织技巧显性化：课文用了哪些学生自己看不出来的组织手段——伏笔与呼应、小转折设计、开头入题方式、结尾升华方式
- 显性化为一份"结构支架"：学生写同类文章时可照着搭骨架的空框架（每段一行，写明该段功能与提示句式）

## Language 层：怎么用语言的
挑 6-8 处迁移价值最高的语言技巧，每处完成三级转化：
1. **课文原句**（英文，标出关键表达）
2. **显性规则**（一句话说清"写什么的时候可以这么写"，如"写紧张不贴 nervous 标签，改写一个身体反应"）
3. **迁移示例**（1 个新情境仿写句——换话题不换技巧）

# 输出格式
Markdown，中文撰写、原文引用与迁移示例用英文：
1. **Meaning**：意图与选材详略
2. **Structure**：结构图式 + 组织技巧 + 结构支架
3. **Language**：6-8 条"原句 → 显性规则 → 迁移示例"
4. **可迁移写作知识清单**：汇总表（写作知识 | 课文证据 | 使用时机 | 迁移练习建议），只收前三层中迁移价值最高的条目

# 例外处理
- `<material>` 为空或不是英语语篇：不要分析，说明需要粘贴一篇英语课文或阅读语篇，不要输出其他内容。
- 语篇过短（不足一个完整的段落结构）：说明材料太短、结构层知识有限，只输出 Language 层并在开头注明。
