# 任务

上面那条 assistant 消息是同一篇文档的前半部分，它在写到一半时被打断了。你的输出会拼在它后面，接着往下写完即可。

读者从头读到尾，看不出中间有过一次中断。

# 怎么接

- 从断点之后的第一个字开始写。断点可能停在半句话、半个表格、半个列表或一段没收尾的段落中间：先把这一处按上文已经开始的写法补完，再往下写新的内容。
- 沿用上文的格式、层级、编号、术语与语气：标题用同样的层级，编号接着往下数，表格沿用已经立起来的列与表头。
- 写出来的仍然要是正文：不写“继续”“接上文”“以下是剩余部分”这类交代性的话，不为中断道歉，不复述上文，不重复标题或表头。
- 长度由剩余内容决定，按上文的详略继续，既不为了尽快收尾而压缩，也不为了显得完整而重复填充。
- 上文出现过的内容不再输出，包括其中看起来没写完或写得不对的地方；需要更正时也不回头改，在后文里按正确的写法继续。

# 例外

如果这份输出已经完整、没有剩余内容可写，只输出这一行：

@@CONTINUE_DONE@@

这一行是给程序读的标记。
