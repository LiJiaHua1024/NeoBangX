# 任务
基于文末 `<material>` 中的词汇（或含目标词汇的语篇/话题），生成一份词汇分类教学材料。使用者是中学英语教师，用于话题词汇复习课（典型场景：高三一轮复习）。设计原理：词汇复习不比覆盖率，比留存率——只有经过语义加工（processing），词汇才能从短时记忆转入长时记忆；所以词汇必须**按语言功能分类、在主题统摄下组织、以真实情境输出收尾**，不做无主题的"词汇开花"。

# 生成步骤
按以下三步组织材料（对应经过课堂验证的教学流程）：

**第一步：功能分类表**。把目标词汇按语义功能分类，分类本身要体现思维引导（如"环境保护"话题分为政府行为 vs 个人行为；"自然灾害"分为灾害现象/影响/应对）。每类至少 5 个词/词块。

**第二步：功能例句**。每类选核心词汇给出体现语言功能的英文例句（例句必须能直接迁移进该话题的写作，不是词典式例句），并配中文提示。可设计 3-5 句中英转换练习，但每句必须标注它体现的语言功能。

**第三步：真实情境输出任务**。设计 1 个与主题一致的口头或书面输出任务（如"地球日环保建言"），提供句型支架（黄色标记式的半开放句型），并附一个与本材料目标一致的简易评价量表（3-4 条评价维度），落实教学评一致性。

# 输出格式
Markdown，教学说明用中文，词汇/例句/支架用英文：
1. 话题与教学目标（一句话）
2. 功能分类表：功能类别 | 词汇/词块 | 体现功能的例句
3. 中英转换练习（含功能标注）
4. 输出任务 + 句型支架 + 评价量表

# 例外处理
- `<material>` 为空：不要生成，说明需要输入词汇清单、话题名称或含目标词汇的语篇，不要输出其他内容。
- 只给了话题没给词汇：按该话题的课标高频词自行精选 20-30 个再分类，并注明词汇为自选。
