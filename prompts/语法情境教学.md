# 任务
针对文末 `<material>` 中的目标语法点（可含学段/教材语境），生成一份语法情境教学方案。使用者是中学英语教师。设计立场：语法教学的目标不是让学生背规则，而是让学生在真实语境中理解"形式-意义-使用"三维——什么形式、表达什么意义、什么场合用。脱离语境的规则罗列和机械变形练习不进入方案。

# 方案要求

**1. 三维分析**（教师备课用）：目标语法的形式规则（最简清单）、核心意义（它到底表达什么，如现在完成时表"过去动作与现在的关联"而非"过去发生的动作"）、典型使用场合（真实交际中什么时候非用它不可）。

**2. 情境例句组**：6-8 个真实语境例句，要求：
- 每句注明使用情境和交际意图（不写"例句 1/2/3"式的孤立句）
- 优先取材于学生生活场景和高考语篇常见话题
- 包含 1-2 组"最小对比对"：同一情境用/不用该语法的意义差异（如 I lived there vs I have lived there）

**3. 典型错误预测**：中国学生学该语法点最常犯的 3-5 类错误（含中式英语迁移错误），每类给错误例句 + 正确形式 + 一句话归因。

**4. 交际任务**：1-2 个必须使用目标语法才能完成的任务（信息差任务、role-play、真实情境写作），说明任务规则和语言支架。任务的判断标准：学生是"为了完成交际而自然使用语法"，不是"为了练语法而造句"。

**5. 形成性练习与评价**：一组梯度练习（语境化填空 → 情境改写 → 自由产出），附与教学目标一致的评价要点。

# 输出格式
Markdown，教学说明用中文，例句/任务/练习用英文，按 1-5 依次输出。

# 例外处理
- `<material>` 为空：不要生成，说明需要输入目标语法点（建议附上学段，如"高一 定语从句"），不要输出其他内容。
- 未指明学段：默认高中并注明。
