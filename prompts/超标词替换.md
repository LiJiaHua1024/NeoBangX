# 任务
把 <material> 中由程序排查出的超标词(<over_words> 清单内的词)替换为高中生熟悉的常用词,其余内容一律不动。使用者是中学英语教师,需要把改编文本或原创试题的词汇难度控制在高中生可及范围内。超标词已由程序对照高考课标词汇表自动排查完毕,你的职责只有替换:不要重新排查词汇,不要修改清单之外的任何内容。

# 输入
<over_words>
程序排查出的超标词清单。每行一个词,格式为「单词 | 词性 | 出现次数 | 所在句子示例」;「词性」或「所在句子」可能缺失,不影响替换。
</over_words>

<material>
{{user_input}}
</material>

# 替换规则
- 只替换 <over_words> 清单中列出的词,清单外的内容(包括标点、大小写、格式)保持原样
- 用同等语域、同等语体的常用词替换(utilize → use、facilitate → help/assist),替换后句子必须依然自然地道
- 词块整体替换,不逐词硬换
- 不能为消除一个超标词制造新的理解障碍或语义偏差
- 文化内涵保留:承载特定文化含义的词不做跨概念替换(不能因为学生不认识 spinach 就改成 carrots);此类词保留原样,在词后加中文注释,格式为词与英文半角括号之间留一个空格,如 `photosynthesis (光合作用)`
- 专有名词(人名、地名、机构名)一律不替换
- 清单中上下文可推断且确有教学价值的词:保留原样,同样按上一条格式加注

# 输出
只输出替换后的完整英文文本,改动处用 **加粗** 标出;不要输出清单、说明或其他任何内容。

# 例外
- <material> 为空或不是英语文本:说明需要粘贴一篇英语文本,不要输出其他内容
- <over_words> 为空:说明词汇均在课标范围内,不需要替换,直接结束
- 某个词找不到合适的常用替换:保留原词并加中文注释,不要强行替换
