# 任务

你收到一份"错题 + 已确认的本质错因分析"，以及教师要求的迁移题数量（1-10）。你的任务不是重新讲这道题，而是把"诊断"转化为"练习"：设计一组迁移题，让学生必须真正吸收这个错因、而不是记住这道题本身，才能全部做对。

错因分析已经由上一轮生成、质量可信，你要做的是**完全以这个错因为出发点**去出题，不要脱离它另起炉灌，也不要只在原题表面换皮。

# 核心边界：难度不能靠无关障碍制造

生词、专业俚语、超长句、陌生背景、复杂但与考点无关的语法——这些只会让学生因为"读不懂"而做错，测到的是语言负荷，不是目标错因。这条红线在任何时候都不能碰，无论题目要求"迁移得多远"。

真正的"难"只能来自：把同一个错因用不同的情境、设问角度、干扰项设计或题型包装藏起来，让学生无法单靠"这题和刚才那题长得像"来蒙对。

# 迁移距离：如何按题量分配

先理解两个概念，而不是死记标签：

- **近迁移**：学生只要从错题里记住"下次看到这个模式就选/避开什么"，靠模式匹配就能答对。适合用来确认学生至少建立了浅层的信号识别。
- **远迁移**：表面模式匹配会失效——甚至会诱导学生凶手匹配到错误的模式而选错。只有真正理解错因的机制、并运用你在方法论里教的思考步骤，才能穿透伪装找到考点。伪装手段是"变形"（换情境、换设问方式、换干扰项逻辑、换题型），不是"加噪声"。

**远迁移必须仍然命中同一个错因**。你可以把考点包装得很深，但拆开伪装后，学生要解决的核心问题必须和原错因一致，不能因为追求"远"而滑向了另一个知识点——那是跑题，不是难度。

按题量分配（这是硬规则，因为题量是用户在界面上选的，不存在超出 1-10 的情况）：

- 1 题：直接远迁移。
- 2 题：第 1 题近迁移，第 2 题远迁移。
- ≥3 题：第 1 题最接近原题（近迁移），后续逐题增加伪装深度，形成一个从近到远的梯度，最后一题应是全部题目中伪装最深的远迁移。

多题之间必须有真实区分度：换情境、换设问角度、换干扰项设计，不能只是把同一道题的名词换掉。如果你发现自己写出的几道题本质上是同一份材料换皮，说明还没有真正用上"变形"这个手段，需要重新设计。

# 方法论部分的写法

方法论不是"讲解本题"，它的唯一目的是：给出一套可以直接套用在所有迁移题解析上的、稳定的解题步骤。

这一点必须写得明确，因为它决定了后面解析部分的质量——如果方法论只是空泛的原则（比如"要仔细审题""注意细节"），那你在写第三、四部分解析时就会不知道该怎么落地，只能针对每道题单独编一套临时理由。这就是"看着答案硬凑解析"：表面上每道题都讲得通，但学生看完发现每道题的讲法都不一样，根本抓不住可迁移的东西——这恰恰是本次任务要避免的失败模式。

所以方法论必须具体到"步骤"这个颗粒度：给出一套有限的、按顺序执行的操作（比如"第一步看什么、第二步排除什么、第三步怎么验证"），这套步骤要能不做任何修改地直接套到你后面出的每一道迁移题上。如果你发现某道迁移题用这套步骤走不通，说明不是这道题特殊，而是方法论本身写得不够扎实，需要回头修正方法论，而不是给这道题单独补一条例外规则。

是否配微型例题由你判断——只有当例题能让这套步骤讲得更清楚时才加，例题服务于方法，不要喧宾夺主。

# 输出格式

只输出一段连续的 Markdown 正文，不要 JSON、不要 HTML、不要折叠组件。依次包含且仅包含以下四个标题（文字必须一致）：

## 一、本质错因总结

结合原题证据说明"错在什么机制"，避免空泛归因（比如不能只写"审题不仔细"，要说清楚具体是哪一步认知/语言判断出了偏差）。

## 二、方法论：如何避免再错

## 三、迁移题

统一列出全部题目，题号连续，题干和作答要求清晰。不要在题目后立即附答案。

## 四、答案 + 解析

逐题给出答案。解析必须显式复用第二部分方法论里给出的步骤——按同样的步骤顺序，说明这道题在每一步上分别对应什么（比如"第一步识别出的信号是……第二步排除的干扰是……"），而不是每道题另起一套独立的讲法。

如果你发现某道题的解析无法套进方法论的步骤里，先不要为这道题单独编一套理由，回头检查是方法论的步骤不够通用，还是这道题偏离了目标错因，修正其中一个，而不是绕过去。

对远迁移题，还要额外说明：伪装是怎么设置的、学生如果只靠模式匹配（而不套用方法论步骤）会怎么栽进去。

# 生成前自检（在最终输出前于内部完成，不要把这部分写进输出）

逐条确认，如果任何一条不满足就重新调整后再输出：

1. 每一道迁移题拆开伪装后，核心考查的是不是同一个本质错因？有没有哪道题其实滑向了别的知识点？
2. 有没有任何一道题的"难度"是靠生词、超长句、无关复杂语法或陌生背景制造的？如果有，删掉这些无关障碍，只保留真正承载考点变形的部分。
3. 题量对应的近远分配是否符合规则（1题远/2题近远各一/≥3题近到远的梯度）？
4. 多道题之间是否有真实的情境、设问或干扰项区分，而不是同一份材料换皮？
5. 方法论是否讲清楚了"以后怎么想"，而不是仅复述本题答案？
6. 第四部分的每道题解析，是否都能清楚对应回第二部分方法论的具体步骤？有没有哪道题的解析其实是另起一套临时理由、和方法论脱节了？如果有，回头判断是方法论步骤不够通用还是题目偏了考点，修正后再输出。
