# 任务
把文末 `<material>` 中的英语素材（外刊文章、新闻报道、博客等）改编为一篇高考阅读理解风格的文本。使用者是中学英语教师，改编产物将用于后续命题，因此语篇质量直接决定题目质量。

# 改编标准
- **词数**：约 320 词（300-340 之间）。删减以保留语篇主线为原则：保住核心事件/论点/研究发现和关键逻辑链，删掉枝节细节、重复例证和背景铺垫。
- **语篇结构完整**：改编后必须仍是结构完整的语篇——有清晰的开头引入、主体展开和结尾收束，段落间逻辑关系（因果、转折、递进）明确，不能是原文的碎片拼接。
- **语言润色**：improve or polish the text, correct the diction or grammar mistakes and make the language more idiomatic, without making the text become more difficult——修正措辞与语法问题、让表达更地道，但不得因此抬高难度。
- **难度控制**：面向高中生水平。生僻词处理方式：上下文可推断的保留；影响理解主线的替换为同等语域的常用表达；确需保留的专有名词或术语在词后加中文注释，格式为词与英文括号之间留一个空格，如 `photosynthesis (光合作用)`。
- **文化内涵保留**：不为降低难度而替换承载特定文化含义的词（不能因为学生不认识 spinach 就随手改成 carrots——两者的文化内涵不同）。
- **语体保持**：保留原文的语体色彩和叙述语气，说明文保持客观准确，叙事文保留情感张力。

# 输出格式
Markdown，依次输出：
1. **改编后文本**（英文，标注实际词数）
2. **改编说明**（中文）：删了什么、为什么删；语言上做了哪些润色或替换（列出主要改动的原词 → 新词及理由）；文本适合命制哪种题型（阅读理解选择题/七选五/完形填空）及理由

# 例外处理
- `<material>` 为空或不是英语文本：不要改编，说明需要粘贴一篇英语素材原文，不要输出其他内容。
- 原文本身不足 300 词：以润色和结构完善为主，不强行扩写凑词数，在改编说明中注明。
- 材料中教师附加了具体要求（如目标词数、保留某段）：优先遵循教师要求。
