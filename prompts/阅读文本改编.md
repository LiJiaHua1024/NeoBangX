# 任务
把文末 `<material>` 中的英语素材（外刊文章、新闻报道、博客等）改编为一篇高考阅读理解风格的文本。使用者是中学英语教师，改编产物将用于后续命题，因此语篇质量直接决定题目质量。

难度设计遵循「词汇考查真实化」方向：难度不堆生僻词，而来自基础词的地道组合与灵活活用——把「词的陌生」转向「熟词的陌生组合」，让文本贴近真实语篇、符合高考命题方向。

# 改编标准
- **词数**：约 320 词（300-340 之间）。删减以保留语篇主线为原则：保住核心事件/论点/研究发现和关键逻辑链，删掉枝节细节、重复例证和背景铺垫。
- **语篇结构完整**：改编后必须仍是结构完整的语篇——有清晰的开头引入、主体展开和结尾收束，段落间逻辑关系（因果、转折、递进）明确，不能是原文的碎片拼接。
- **语言润色**：修正措辞与语法问题、让表达更地道，但不得因此抬高难度。
- **词汇真实化改造**：在润色的同时从三个维度注入原汁原味的表达：
  1. **地道词块**：用基础词组成的地道短语替换平淡表达，如 hit home（使人深切意识到）、weed out（筛除）、set sb up for（为将来做准备）
  2. **词性活用**：名词动用、动词名用等，如 spot 作动词指发现、power 作动词指驱动、cover 作动词指讲授
  3. **合成词与连字符表达**：如 go-to destination、headline-grabbing、color-coded
- **同义替换**：全文避免同一词汇重复，用地道的同级替换（review → write-up、change → shift/transition、good choice → sure bet），替换后的语域与原文语体匹配。
- **难度控制**：面向高中生水平。生僻词处理方式：上下文可推断的保留；影响理解主线的替换为同等语域的常用表达；确需保留的专有名词或术语在词后加中文注释，格式为词与英文括号之间留一个空格，如 `photosynthesis (光合作用)`。
- **文化内涵保留**：不为降低难度而替换承载特定文化含义的词（不能因为学生不认识 spinach 就随手改成 carrots——两者的文化内涵不同）。
- **语体保持**：保留原文的语体色彩和叙述语气，说明文保持客观准确，叙事文保留情感张力。
- **改造底线**：所有改造用词都是高中生认识的基础词，不引入真正的生僻词。改造点优先选天然自带语境线索的表达——紧邻上下文里已有解释、举例、因果或转折能支撑词义的才改造，给不出线索的宁可不改、不硬塞。这是改造点成为命题考点的前提。

# 输出格式
Markdown，依次输出：
1. **改编后文本**（英文，标注实际词数）
2. **改编与词汇改造说明**（中文）：
   - 删了什么、为什么删
   - 改造清单（Markdown 表格）：原表达 → 改造后表达、类型（润色/词块/活用/合成词/同义替换）、语境含义、理由或命题价值
3. **命题建议**（中文，3-5 行）：哪些改造点适合出词义猜测题或用于完形设空；文本适合命制哪种题型（阅读理解选择题/七选五/完形填空）及理由

# 例外处理
- `<material>` 为空或不是英语文本：不要改编，说明需要粘贴一篇英语素材原文，不要输出其他内容。
- 原文本身不足 300 词：以润色和结构完善为主，不强行扩写凑词数，在改编说明中注明。
- 原文已经高度地道（如外刊原文）：以结构调整和词数控制为主，改造清单改为标注原文中已有的真实化词汇考查点。
- 材料中教师附加了具体要求（如目标词数、保留某段、不做词汇改造）：优先遵循教师要求。
