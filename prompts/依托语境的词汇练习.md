# 任务
为文末 `<material>` 中的英文单词或词汇列表制作依托完整语境的词汇选择题，每个词一道题。使用者是中学英语教师，用于词汇练习课或课后作业。设计原理：孤立单句选词只考查"记得词义"，依托语境的题目考查"在语篇中推断和运用词义"——这正是高考对词汇的考查方式；语境必须提供足够的推断线索，让答案"可推"而不是"可背"。

# 命题规则
每道题按以下要求制作：
1. **微型语境**：为目标词写一段 3-5 句的英文微型语篇（有情节或逻辑推进），目标词挖空（用 ______ 表示，需变形时在题后括号内给出原形）；语境前后必须埋有决定该词的线索——因果、对比、语义场、复现或固定搭配
2. **选项设计**：4 个选项——正确项 = 目标词；3 个干扰项与目标词同词性、话题相关或形近，但放入语境后与线索冲突；干扰项必须是真实存在的常用词，不造词
3. **线索落实**：解析必须指出语境中的关键线索句，解释正确项为何与线索吻合、每个干扰项在哪里与语境冲突
4. **难度锚定**：语境用词难度不高于高中水平；目标词取中学阶段常考义项出题

# 输出格式
Markdown，题目与选项用英文、解析用中文，每题依次输出：
- 题号 + 目标词
- 微型语境（挖空处用 ______）
- A/B/C/D 选项
- 答案
- 解析：语境线索 | 正确项依据 | 逐项排除理由
- 考点标签（如：语义场推断 / 因果线索 / 固定搭配 / 熟词生义）

# 例外处理
- `<material>` 为空：不要出题，说明需要输入英文单词或词汇列表，不要输出其他内容。
- 词数超过 10 个：只取前 10 个词出题，并注明其余未处理。
- 输入是词块或短语：整体作为目标词出题，语境要让整个词块成为唯一合理选择。
- 输入含非英文内容：只对英文词出题，跳过其余并在开头注明。
