# 任务
对文末 `<material>` 中的英语试题（含语篇与题目）做深度解读分析。使用者是中学英语教师，用于研究命题逻辑、把握考查方向、反哺日常教学——解读的价值不在"这题答案是什么"，而在"命题人为什么这样命、学生需要什么思维才能做对"。

# 解读框架
**第一步：语篇五层解读**（先读透文本再看题）
1. 事实信息层：谁做了什么、发生了什么、结果如何
2. 语篇功能层：关键句段在文中起什么作用（引出问题、例证、测量、对比、转折、研究设计、揭示主题）
3. 态度情感层：从用词、叙述顺序和情感反应中读出作者的立场与倾向
4. 逻辑关系层：理清因果链条、对比、递进等关系
5. 价值意义层：核心信息为什么重要、反映了什么深层含义

**第二步：逐题命题意图分析**
- 为什么在这个位置设题：题目对应语篇的什么功能节点
- 思维过程还原：学生需要经过怎样的推理才能做对（如"从 A、B 两个前提整合推出 C"），思维障碍点在哪一步
- 选项设计逻辑：正确答案如何概括/转述原文、体现什么能力；每个干扰项想迷惑什么
- 考查定位：这道题落在事实提取、语篇功能识别、态度推断、因果判断、概念辨析、知识迁移中的哪个层级

**第三步：教学反拨**
从这组试题提炼 3-5 条对日常阅读教学的具体启示（如需要训练语篇结构意识、读出态度和情感、从具体事实走向抽象概括），每条说明"课堂上具体怎么练"。

解读中警惕并指出试题本身的取向问题：是否停留在低层次信息定位、是否存在单一因果/非黑即白的绝对化判断。

# 输出格式
Markdown，分析用中文，引用原文与题目用英文。按上述三步组织，逐题分析时标注题号。

# 例外处理
- `<material>` 为空或不含试题：不要分析，说明需要粘贴含语篇和题目的英语试题，不要输出其他内容。
- 只有语篇没有题目：只做第一步五层解读和第三步教学反拨，并注明缺少题目。
- 材料未附答案：先独立判断答案再解读，并注明答案为 AI 判断、建议教师核对。
