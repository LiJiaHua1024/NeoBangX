# 任务
对文末 `<material>` 中的英文课文或阅读语篇做"教考衔接"分析，打通教学与考试：这个语篇该怎么教（教学设计）、考试会怎么考（语用功能设问）、思维品质怎么落（思维品质培养）。使用者是中学英语教师。设计原理：高考设问与语篇结构呈镜像映射，考查重心已从细节定位转向语篇的语用功能与思维品质；只有按"考试怎么考"来教"文本怎么读"，教学才能真正衔接考试。

# 分析框架
按以下四个层面递进分析，各层面的判断都必须引用原文关键句作证据：

## 层面一：文本深度解读
- **What**：主题语境归属、核心信息链（不逐句翻译）
- **Why**：作者写作意图与主题意义，用一句话点透
- **How**：语篇结构模式 + 逐段功能；提炼 5-8 条结构化知识，每条含三项：语言形式、表达功能、使用情境，只选写作迁移价值最高的

## 层面二：教学设计
基于层面一的解读给出简案：
- 教学目标：理解-应用-迁移三层级各一条
- 问题链：3-4 个引导学生自己发现语篇结构与语言功能的主问题
- 读后输出任务：1 个与课文结构、语言对接的真实情境写作任务

## 层面三：语用功能设问
命制 3-4 道高考风格的阅读理解选择题（含选项与答案）：
- 设问落在语篇的语用功能节点上（主题引入、段落转折、核心发现、态度立场），不问孤立细节
- 每题标注三项：设问位置的语篇功能、对应的高考题型特征、干扰项设计策略
- 正确选项基于文本证据推断或用上位概念概括，不重复原文原句

## 层面四：思维品质培养
- 梳理本语篇的思维品质培养落点：逻辑性（因果、比较、分类）、批判性（评价、质疑、辨别）、创新性（迁移、创编）
- 设计 2-3 个超越"读懂"层级的思维活动（如评价作者论证是否有力、把课文结构迁移到新话题创编提纲）
- 说明各落点如何对接高考的高阶思维考查（推理判断题、作者态度题、读后续写的情节创编）

# 输出格式
Markdown，中文撰写、原文引用用英文，按"一、文本深度解读 / 二、教学设计 / 三、语用功能设问 / 四、思维品质培养"四节输出。

# 例外处理
- `<material>` 为空或不是英语语篇：不要分析，说明需要粘贴一篇英文课文或阅读语篇，不要输出其他内容。
- 材料是试题或试卷而非课文/语篇：说明本工具面向课文与阅读语篇，建议改用"试题解读分析"，不要输出其他内容。

# 排版（视觉可读性）
输出是给人读的 Markdown，渲染后的视觉可读性优先：并列信息用表格，层级关系用列表，结论与关键信息用加粗，原文引用用引用块或斜体，说明性长段落拆成短句、短段。输出中引用的原文、例句、题目与学生习作原样照录（包括其中的错误），润色、缩写、纠错只做任务明确要求的事；上文已定死的标题、条目、题号与固定模板不变，本节只约束其余行文。
