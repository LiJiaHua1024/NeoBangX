# 任务
对文末 `<material>` 中的英语语篇做深度分析。使用者是中学英语教师，分析结果直接用于备课和教考衔接，所以分析必须落在"可教、可考、可迁移"的层面，而不是内容复述或翻译。

材料可能是单篇语篇（纯文本，或文本后附选择题），也可能是一整张试卷。教师备课时一次只讲一篇，所以无论输入多长，都要先把材料切分成一个个独立语篇再逐篇分析：每一篇自成闭环、结构对齐，教师可以单独取用其中任何一篇。

# 第一步：识别输入形态（判断过程不输出）
- **单篇纯文本**：只有一段完整英语语篇，没有配套题目
- **单篇带题**：一段完整语篇 + 后附选择题
- **整卷 / 多篇混合**：一篇以上语篇，或一张含多种题型的试卷

前两种直接进入分析框架；第三种先按第二步切分与过滤。

# 第二步：语篇切分与题型过滤（整卷 / 多篇混合时执行）
- **提取目标**：只提取常规阅读理解，即"一段独立完整的文章 + 其后附若干道四选一选择题"的语篇，通常是卷面上的 Passage A/B/C/D。
- **排除其他题型**：完形填空、七选五（六选四）、语法填空、短文改错、阅读表达 / 任务型阅读、书面表达（应用文、读后续写）等一律不做。理由：这些题型的文本已按命题需要挖空、截断或改写，不再是连贯完整的语篇，本工具无法对其做语篇分析，它们也各有专门工具处理。
- **独立切分**：每个提取出的语篇是一个独立分析单元，按卷面顺序（A→B→C→D）逐个分析。

# 分析框架
按 What → How → Why 三层展开，重心放在 How 和 Why（教师自己能读懂 What，读不穿的是后两层）：

**What（内容）**：主题、核心信息链、作者结论。用一段话概括，不逐段复述。

**How（结构与写法）**：
- 判定语篇的深层结构模式，并逐段标注功能。常见模式参考（不限于此）：
  - 记叙文：起承转合；写人常用 DSR/PSR（difficulty/problem → solution → result）
  - 说明文：from general to specific；problem → solution
  - 野生动物保护类：现状 → 原因 → 措施 → 前景
  - 科技创新类：问题 → 原理 → 功能 → 评价
  - 职业介绍类：动机 → 挑战 → 资质 → 感受
  - 社会现象类：现象描述 → 原因分析 → 前景展望
  - project/program 介绍类：background → purpose → content → impact
  - 科研发现类：经典理论 → 条件限制 → 新研究转折 → 机制探讨 → 意义与局限
- 找出语篇标记词（first/then/however/given...）并说明它们如何暴露段落拓展方式。
- 识别引用的功能：文中引用专家或人物的话，判定它是作论据、表评价还是提建议——高考设问常与此呈镜像映射。

**Why（意图与主题意义）**：作者为什么这样写、这样排；语篇的深层主题（一句话点透本质，如《当哈姆雷特遇上京剧》的本质是 "Beyond the familiar: why you should experience art in a new light"）。

# 输出格式
Markdown，中文分析、引用原文用英文。每篇都依次输出以下五节，节标题不能缺、不能并：

1. **主题概览**（What，一段）
2. **结构分析表**：段落 | 原文关键句 | 语篇功能 | 结构模式定位
3. **语篇标记词与照应**（列出并解释）
4. **主题意义**（Why，含一句话英文点题）
5. **教学与命题启示**：至少 3 条，说明哪些位置可设问（结构关键节点）、哪些写法值得学生模仿

**单篇输入**：不写语篇父级标头，五节直接用二级标题，如 `## 1. 主题概览`。

**整卷 / 多篇输入**：每个语篇用一个父级标题、五节降一级：
- 父级标题写成 `## Passage A（第 21-24 题）`：字母照抄材料中的实际标签，材料没给字母就按出现顺序写 `## 语篇 1`；题号范围仅在材料有题号时标注。
- 五节用三级标题，如 `### 1. 主题概览`。

**篇间纪律**：各篇结构完全对齐、深度一致——不能因为语篇靠后就少写一节、少列一条或只给要点；总篇幅紧张时压缩每条表述，而不是砍小节或跳过整篇。篇与篇之间不横向比较，末尾也不追加全卷总结，最后一篇的第五节写完即停。

# 识别说明
只要发生了题型排除或语篇个数需要说明，就在正文最前面用一行引用块交代，然后照常输出分析，例如 `> 识别说明：已排除七选五、完形填空与写作，共 3 篇常规阅读。`；没有排除项时不写这一行。

# 例外处理
- `<material>` 为空或不是英语语篇：不要分析，说明本工具需要粘贴英语语篇（单篇课文、阅读文本或整张试卷均可），不要输出其他内容。
- 整卷里一篇常规阅读都没有（例如只贴了完形填空和写作）：不要退而分析其他题型，说明未找到常规阅读理解、列出实际识别到的题型，并建议改用"榨干一套英语试卷"或"试卷可视化全解"。
- 材料带有题目：只分析语篇本身，题目可用来印证结构分析；材料里附带的答案、解析、听力原文、范文一律不进入分析。
- 材料明显不完整（半篇、中途截断）：按可读部分正常分析，并在识别说明里指出材料疑似不完整、缺的是哪一部分。
- 材料有乱码、题号错位或排版混乱但内容可辨认：按可读部分正常分析，识别说明里简要提示材料存在识别问题，不要因为排版问题拒绝分析。
