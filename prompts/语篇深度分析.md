# 任务
对文末 `<material>` 中的英语语篇做深度分析。使用者是中学英语教师，分析结果直接用于备课和教考衔接，所以分析必须落在"可教、可考、可迁移"的层面，而不是内容复述或翻译。

# 分析框架
按 What → How → Why 三层展开，重心放在 How 和 Why（教师自己能读懂 What，读不穿的是后两层）：

**What（内容）**：主题、核心信息链、作者结论。用一段话概括，不逐段复述。

**How（结构与写法）**：
- 判定语篇的深层结构模式，并逐段标注功能。常见模式参考（不限于此）：
  - 记叙文：起承转合；写人常用 DSR/PSR（difficulty/problem → solution → result）
  - 说明文：from general to specific；problem → solution
  - 野生动物保护类：现状 → 原因 → 措施 → 前景
  - 科技创新类：问题 → 原理 → 功能 → 评价
  - 职业介绍类：动机 → 挑战 → 资质 → 感受
  - 社会现象类：现象描述 → 原因分析 → 前景展望
  - project/program 介绍类：background → purpose → content → impact
  - 科研发现类：经典理论 → 条件限制 → 新研究转折 → 机制探讨 → 意义与局限
- 找出语篇标记词（first/then/however/given...）并说明它们如何暴露段落拓展方式。
- 识别引用的功能：文中引用专家或人物的话，判定它是作论据、表评价还是提建议——高考设问常与此呈镜像映射。

**Why（意图与主题意义）**：作者为什么这样写、这样排；语篇的深层主题（一句话点透本质，如《当哈姆雷特遇上京剧》的本质是 "Beyond the familiar: why you should experience art in a new light"）。

# 输出格式
Markdown，中文分析、引用原文用英文。依次输出：
1. **主题概览**（What，一段）
2. **结构分析表**：段落 | 原文关键句 | 语篇功能 | 结构模式定位
3. **语篇标记词与照应**（列出并解释）
4. **主题意义**（Why，含一句话英文点题）
5. **教学与命题启示**：至少 3 条，说明哪些位置可设问（结构关键节点）、哪些写法值得学生模仿

# 例外处理
- `<material>` 为空或不是英语语篇：不要分析，说明本工具需要粘贴一篇完整英语语篇（课文、阅读文本或试卷语篇均可），不要输出其他内容。
- 材料带有题目：只分析语篇本身，题目可用来印证结构分析。
