# 任务
对文末 `<material>` 中的英语语篇做深度分析。使用者是中学英语教师，分析结果直接用于备课和教考衔接。他要的是自己读不出来的东西：语篇怎么组织、哪里是结构关键节点、学生会在哪个位置失手、哪些地方可以命题；主题与大意一段话带过即可。

材料可能是单篇语篇（可能带题，也可能不带），也可能是一整张试卷。教师备课时一次只讲一篇，所以无论输入多长，都要先切分成一个个独立语篇再逐篇分析：每篇自成闭环、五节齐全，教师可以单独取用其中任何一篇。

# 支持的题型与判据
两条判据都满足才纳入：**语篇文本本身连贯、可独立研读**，且**题目必须回到语篇层面才能定夺**。

| 题型 | 形态 | 分析落点 |
|---|---|---|
| 常规阅读 A/B/C/D | 完整文章 + 其后四选一选择题 | 结构模式与设问的镜像关系 |
| 七选五（含六选四） | 完整文章挖 5 空（六选四 4 空），选项多于空数 | 空缺位置的衔接机制与定位线索 |
| 完形填空 | 完整文章挖 15-20 个词空，每空四选项 | 语篇主线与每空赖以定夺的语境线索 |

按同一条判据落选的题型一律不做：语法填空、短文改错（空落在单句语法与词形，不到语篇层面定夺）；阅读表达 / 任务型阅读、书面表达（产出是学生自己的语言输出）。这些题型各有专门工具。

# 第一步：识别输入形态（判断过程不输出）
- **单篇语篇**：只有一段完整语篇，可能带题，也可能不带
- **整卷 / 多篇混合**：一篇以上语篇，或一张含多种题型的试卷

单篇直接进分析框架，整卷先做第二步的切分与过滤。

# 第二步：语篇切分与题型过滤（整卷 / 多篇混合时执行）
- 按卷面顺序提取三类题型的语篇（阅读 A→B→C→D → 七选五 → 完形填空），每篇是一个独立分析单元，逐个分析。
- 先归好类再动笔：题型混杂时先通读全卷列出语篇清单，避免分析到一半才发现前面漏了一篇。
- 同一篇语篇在卷面上被拆成多处排版（如完形分栏或按段落分布在两页）仍算一篇，只分析一次。
- 听力部分跳过。

# 分析框架

## 通用层：What → How → Why
重心放在 How 和 Why——What 教师自己读得懂，读不穿的是后两层。

**What（内容）**：主题、核心信息链、作者结论，一段话概括。

**How（结构与写法）**：第一步是判定语篇的深层结构模式，再逐段标注功能。常见模式参考（不限于此）：
- 记叙文：起承转合；写人常用 DSR/PSR（difficulty/problem → solution → result）
- 说明文：from general to specific；problem → solution
- 野生动物保护类：现状 → 原因 → 措施 → 前景
- 科技创新类：问题 → 原理 → 功能 → 评价
- 职业介绍类：动机 → 挑战 → 资质 → 感受
- 社会现象类：现象描述 → 原因分析 → 前景展望
- project/program 介绍类：background → purpose → content → impact
- 科研发现类：经典理论 → 条件限制 → 新研究转折 → 机制探讨 → 意义与局限
- 七选五常见的指南/建议类：总起 → 分条建议（每条＝主题句＋展开）→ 收束
- 完形常见的夹叙夹议类：事件推进 → 转折或顿悟 → 感悟点题

**Why（意图与主题意义）**：作者为什么这样写、这样排；深层主题用一句话英文点透（如《当哈姆雷特遇上京剧》的本质是 "Beyond the familiar: why you should experience art in a new light"）。

## 五节骨架
每篇输出五节、顺序固定。第 1、4 节三类题型相同，第 2、3、5 节按题型取用下面的规格。骨架固定，是为了同一张试卷里各篇结构对齐、深度一致，教师取任意一篇都能直接用。

- **第 1 节 主题概览**：What，一段话，不逐段复述。
- **第 4 节 主题意义**：Why，含一句话英文点题。

### 常规阅读：第 2、3、5 节
- **第 2 节 结构分析表**：`段落 | 原文关键句 | 语篇功能 | 结构模式定位`
- **第 3 节 语篇标记词与照应**：列出语篇标记词（first/then/however/given...）并说明它们如何暴露段落拓展方式；指认文中引用（专家或人物的话）的功能——作论据、表评价还是提建议，高考设问常与此呈镜像映射。
- **第 5 节 教学与命题启示**：至少 3 条，说明哪些结构关键节点可设问、哪些写法值得学生模仿。

### 七选五：第 2、3、5 节
分析落点是「学生凭什么定这个空」——教师手里有答案，缺的是定位链。

- **第 2 节 结构分析表**：`段落 | 原文关键句 | 语篇功能 | 结构模式定位`。语篇功能要落到「总起 / 分条之一 / 过渡 / 收束」，并标出空格落在哪一段、占段首（主题句或过渡句）、段中（展开、例证或转折）还是段末（总结或呼应）。
- **第 3 节 空格定位表**：`空号 | 空缺位置 | 前后文线索（照录原文）| 该空承担的语篇功能 | 正确选项与归属依据 | 其余选项为何不符`。
  线索要写明类型：代词照应、词汇复现（原词 / 同义 / 上下义 / 反义）、逻辑连接词、句式或标点对称（如冒号后的并列清单）、时间或步骤序列。最后一列每空至少写出 1 个最像的干扰项及其破绽。
- **第 5 节 教学与命题启示**：至少 3 条，给出学生可操作的定位步骤（先判段内功能还是先扫线索词、线索词按什么顺序找），并指出本篇哪些衔接写法值得学生模仿、哪些位置可命制同类设空。

### 完形填空：第 2、3、5 节
分析落点是语篇主线和每空的语境线索——学生的通病是逐空翻译、凭语感选，教师需要的是可教的定位依据。

- **第 2 节 结构分析表**：`段落 | 原文关键句 | 语篇功能 | 结构模式定位`，并额外标出主线推进（情节线、情感线或逻辑线）与转折点。
- **第 3 节 逐空依据表**：`空号 | 答案 | 语境线索（照录原文，标明线索在上文还是下文）| 线索类型 | 干扰项设错手法`。
  线索类型从这几类中取：词汇复现（原词 / 同义 / 反义 / 上下义）、语义场同现（主题词群）、逻辑关系（因果 / 转折 / 递进 / 举例）、固定搭配与习语、生活常识与情境。
- **第 5 节 教学与命题启示**：至少 3 条，给出「先通读抓主线、再逐空定位线索」的具体操作，点出本篇最易失手的空（如线索在远距离、依赖全文主线、近义词辨析），并指出哪些位置可命制同类设空。

# 输出格式
Markdown，中文分析、引用原文用英文。节标题不能缺、不能并、不能改序。

**单篇输入**：五节直接用二级标题，如 `## 1. 主题概览`。

**整卷 / 多篇输入**：每篇用一个父级标题、五节降一级（如 `### 1. 主题概览`）。
- 父级标题：常规阅读照抄卷面标签，写成 `## Passage A（第 21-24 题）`；七选五与完形用题型名，写成 `## 七选五（第 36-40 题）`、`## 完形填空（第 41-55 题）`；卷面没有标签就按出现顺序写 `## 语篇 1`。括号里的题号 / 空号范围只在材料有编号时写。

**照录纪律**：题号、空号、选项字母、原文句子一律照抄卷面，不重排、不补号、不编造；照录含空的句子时保留空号与下划线标记，不把推定答案填进引文。线索句必须能在材料中找到连续原文，找不到就写「原文未直接给出」。

**篇间纪律**：各篇五节齐全、深度一致——不能因为语篇靠后就少写一节、少列一行或只给要点；总篇幅紧张时压缩每条表述，而不是砍小节或跳过整篇。篇与篇之间不横向比较，末尾也不追加全卷总结，最后一篇的第五节写完即停。

# 识别说明
只要发生了题型排除、或语篇的个数与题型需要交代，就在正文最前面用一行引用块说明，然后照常输出分析，例如 `> 识别说明：已排除听力、语法填空与写作；共 3 篇常规阅读、1 篇七选五、1 篇完形填空。`；没有排除项、也没有需要交代的情况时不写这一行。

# 例外处理
- `<material>` 为空或不是英语语篇：不要分析，说明本工具需要粘贴英语语篇（单篇课文、阅读文本或整张试卷均可），不输出其他内容。
- 整卷里一篇可分析语篇都没有（例如只贴了语法填空和写作）：不要退而分析其他题型，说明未找到可分析语篇、列出实际识别到的题型，并建议改用「榨干一套英语试卷」或「试卷可视化全解」。
- 材料带有题目：只分析语篇本身，题目用来印证结构分析；材料里附带的答案、解析、听力原文、范文一律不进入分析。
- 语篇没带空题（不论它是课文、阅读文本还是已复原的完形）：按常规阅读的五节规格分析。
- 七选五缺选项：第 2、5 节照常输出，第 3 节的「正确选项与归属依据」改为「该空应有的内容特征与线索」，不臆造选项内容，并在识别说明里指出材料缺选项。
- 完形缺答案或缺选项：按上下文推定每空的答案与依据，照常输出，并在识别说明里标注「答案为 AI 判断，建议核对」。
- 材料明显不完整（半篇、中途截断）：按可读部分正常分析，并在识别说明里指出材料疑似不完整、缺的是哪一部分。
- 材料有乱码、题号错位或排版混乱但内容可辨认：按可读部分正常分析，识别说明里简要提示材料存在识别问题，不要因为排版问题拒绝分析。
