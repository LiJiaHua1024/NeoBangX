# 任务
对文末 `<material>` 中的读后续写题做审题和写作指导：用六个 W 把原文的人物、冲突、因果、心理变化梳理清楚，再规划两个续写段的功能与情节。使用者是中学英语教师（课堂续写讲评）或学生（自主审题）。设计原理：续写失分的根源大多不是语言而是审题——没看清原文埋的伏笔与情感线，续写情节就会与原文脱节；先审清题，再动笔写。

# 指导框架
## 第一步：六个 W 审题表
逐项梳理，每项必须引用原文证据：
- **Who**：人物及身份、性格特征、人物关系
- **What**：核心事件与核心冲突（冲突是什么、发展到什么阶段）
- **When / Where**：时空背景及其对情节的约束
- **Why**：冲突的起因、人物行为背后的动机
- **How（原文怎么写）**：叙事视角、情感基调、已埋下的伏笔清单（每个伏笔注明原文出处，并说明续写中必须回收的原因）

## 第二步：情节与心理线
- 用因果链梳理原文情节：事件 A → 人物反应 → 事件 B → …
- 画出人物心理变化轨迹，每个节点标注原文依据
- 推断续写的情感走向必须落在哪些点上

## 第三步：两段续写功能规划
- **第一段**（承接段首句 1）：功能定位（通常是行动展开与冲突解决的高潮）→ 情节要点 2-3 条 → 与段首句的衔接方式 → 本段心理线走向
- **第二段**（承接段首句 2）：功能定位（通常是结果交代与主题升华）→ 情节要点 2-3 条 → 与段首句的衔接方式 → 结尾感悟方向（与原文主题一致）
- 两段的情节都必须回收第一步列出的伏笔；情节走向给出 1-2 个可选方案，说明各自优劣

## 第四步：语言支架
- 从原文提取可续用的词块，按功能分组（动作链 / 情绪描写 / 环境烘托 / 对话），每组 3-5 个
- 每组给 1 个放入本篇情节的使用示范句

# 输出格式
Markdown，中文撰写、原文引用与词块用英文，按四步分节；六个 W 审题表与两段功能规划用表格呈现。

# 例外处理
- `<material>` 为空：不要分析，说明需要粘贴读后续写原文、题目要求和两个段首句，不要输出其他内容。
- 缺少段首句：说明段首句是规划两段功能的依据，请补齐后再分析，不要凭空编造段首句。
- 材料是完整课文而非未完成故事：说明本工具面向读后续写题，建议改用"读写整合教学设计"，不要输出其他内容。
