# 任务
根据文末 `<material>` 中的写作任务（或文体+话题），生成一份写作教学材料。使用者是中学英语教师。核心立场：高考写作评价已从"考查语言结构"转向"考查思维品质和解决实际问题的能力"——好作文不是把简单意思翻译成复杂英文，而是把模糊意思想清楚、再用准确英文表达；有质量的句子靠清楚的思考，不靠难词。教学材料必须训练思维展开，不堆砌"高级词汇/万能模板"。

# 教学设计要求

**1. 思维链训练**。针对任务要点，示范"观点 → 原因 → 具体情境 → 结果/意义"的展开链。对四类常见思维动作分别给出低水平表达 vs 升级表达对照：
- 理由类：只写好处 → 价值 + 情境 + 结果（如 "Sleep deserves high priority because a tired mind cannot work efficiently. If I stay up late every night, I may sit in class with my eyes open but my brain half asleep."）
- 建议类：只写 should → 对象 + 做法 + 目的
- 感想类：只写感动 → 事件 + 认识 + 以后行动
- 评论类：简单说好 → 态度 + 原因 + 边界条件（什么情况下好、怎么用才好）

**2. 三阶段退支架**。给出可分阶段撤除的支架：
- 阶段一：完整句型支架（I suggest..., because... In this way...）
- 阶段二：只留逻辑词（because / if / in this way / as a result）
- 阶段三：只留追问（What exactly? Why useful? What result?）

**3. 空话升级练习**。写出 3 句该话题下学生最可能写的空话（"It is good for us" 类），每句给三层追问（具体指什么？对谁？什么场景下？）和升级后的英文示范。

**4. 范文**。一篇符合任务要求的范文，配段落功能旁注（中文），标出体现思维深度的句子并说明它好在思考清楚而非用词难。

# 输出格式
Markdown，教学说明用中文，例句/支架/范文用英文，按上述 1-4 依次输出。

# 例外处理
- `<material>` 为空：不要生成，说明需要输入写作题目或"文体 + 话题 + 学段"，不要输出其他内容。
- 只给了话题没给文体：默认按高考常见文体处理并注明假设。
