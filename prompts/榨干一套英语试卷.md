# 任务
对文末 `<material>` 中的英语试卷（或试卷语篇）做语言精华深度拆解，挖掘优质语料，助力学生夯实语言知识、提升地道表达能力。使用者是中学英语教师，用于试卷二次开发——不止是对答案，而是把试卷转化为可讲解、可迁移的写作与语言素材。

# 拆解模块

## 模块一：词类活用、熟词生义与地道表达（全扫雷）

对全卷做三轮独立扫描，每轮只找一类现象，三轮之间不交叉合并：

1. 第一轮：扫描全卷，找出**词类活用**（Parts of Speech Shifts）。

   **目的与范围**：服务于高考备考，只收录高考层面真正有教学价值的**狭义词类活用**——即学生已熟知该词的原有常用词性，在本句中却以另一词性出现，因而可能造成理解障碍、或对写作有直接迁移价值的用法（如 produce 动转名表“农产品”、sideline 名转动表“使边缘化”、string 名转动表“串联”）。

   **明确不收录**：

   - 复合形容词与合成词构词现象（如 AI-powered、well-surfaced、pre-seeded、tech-driven 等“名词/副词 + 分词”结构），这属于构词法而非词类活用；
   - 另一词性已完全词典化、属于初中或高一基础认知的词汇（如 head to 前往、face a problem 面对、book a room 预订），学生无理解障碍，不收录。

   **收录判据**：自问“一个中等水平的高三学生读到此处，是否会因词性转换而产生理解卡顿，或该转化用法是否具有极高的高考写作迁移价值？”两者皆否，坚决不收录。

2. 第二轮：从头再扫全卷，找出所有**熟词生义**（Uncommon Meanings of Familiar Words）——词形简单常见，但此处有特殊或引申义。边界提示：义项与常见义有明显偏离才收录，普通常用义的正常搭配不要为了凑数收录。

   **收录判据**：该义项是否会让一个中等水平的高三学生在阅读时产生误解或卡顿？若该义项他早已掌握（如 book 表"预订"、run 表"经营"中的常见程度），不要收录。

3. 第三轮：从头再扫全卷，找出**地道词组与短语**（Idioms & Collocations）——优先选跨话题、跨语境都能直接套用到写作中的表达，而非仅在本篇语境下成立的一次性搭配。

每一轮内部，条目按其在试卷中出现的语篇顺序排列（阅读A→B→C→D→七选五→完形填空→语法填空……）。每条必须包含：所在语篇标签、完整原句、结合语境的中文解析。

## 模块二：长难句结构剖析
从全卷挑出 2-3 个结构最复杂、最具代表性的长难句：完整原句 / 结构切片（主干、从句、非谓语、倒装等）/ 语法讲解 + 写作启示 + 仿写迁移（英文+中文）。

## 模块三：画面感赏析与模仿写作
从全卷挑出 2 处动作描写生动、动词连用密集、能构建连续可视化动作序列（而非单一静态描写）的句子：完整原句 / 亮点赏析（作者如何用词构建动态推演）/ 模仿写作（新场景仿写，英文+中文）。

# 输出格式
- 模块一：按"词类活用 / 熟词生义 / 地道词组"三个二级标题分类，每类下按语篇分小节，每条格式固定为：
  ```
  **【语篇标签】词/短语（现象类型）**
  原句：……
  解析：……
  ```
  不要在标题行外再套列表符号。
- 模块二、三：逐条展开，中文解析、英文例句。

# 自检（提交前核对，不要输出这部分内容本身）
- 模块一是否真的完成三轮独立扫描，而不是混在一起按语篇列出？
- 每一类是否覆盖了全卷所有语篇？
- 长难句/画面感例句是否是全卷最具代表性的，而非顺手选的前几句？

# 例外处理
- `<material>` 为空或不含英语语篇：不要拆解，说明需要粘贴一套英语试卷或语篇，不要输出其他内容。
- 材料只有单篇语篇：照常按三模块拆解，数量按比例缩减。
- 材料存在明显乱码、题号错位或格式混乱但仍可辨认内容：尽量按可读部分处理，并在输出开头一行简要提示材料存在识别问题。
