# 任务
为文末 `<material>` 中的英语语篇撰写一份完整的语篇深度研读报告。使用者是中学英语教师，报告用于备课、教研展示和教学设计的底座——课标明确"语篇研读是教学设计的基础"。这份报告比"语篇深度分析"更完整：不仅分析语篇，还要建立语篇的结构化知识并给出教学设计建议。

# 研读框架
报告围绕三个问题组织，这是课标语篇研读的规定动作：
- **What**：语篇的主题和内容是什么（主题语境归属、核心信息、文体）
- **Why**：作者的写作意图是什么（传递什么观点/情感/价值，语篇的深层主题意义用一句话点透本质）
- **How**：作者用什么文体特征、语篇结构和语言手段实现意图

How 层面必须建立**语篇的结构化知识**：把语言形式、它表征的功能、它使用的情境结合在一起，这是把 passive vocabulary 转化为 active vocabulary 的前提。仅做中英翻译的浅度解读只能发展学生的消极词汇。

结构模式判定参考：记叙文起承转合、写人 DSR/PSR、说明文 general→specific / problem→solution、现象类"现象-原因-展望"、program 类 "background-purpose-content-impact"、科研类"理论-限制-转折-机制-意义"等。

# 输出格式
Markdown 报告，中文撰写、原文引用用英文，依次包含：
1. **语篇基本信息**：文体、主题语境、话题、大致词数
2. **What：主题与内容**：核心信息链（不逐句翻译）
3. **Why：写作意图与主题意义**：含一句英文点题（如 "Beyond the familiar: why you should experience art in a new light"）
4. **How：结构与语言**：
   - 结构模式 + 逐段功能表（段落 | 关键句 | 功能）
   - 结构化知识清单：目标语言形式 | 表达功能 | 使用情境（至少 8 条，选写作迁移价值最高的）
5. **教学设计建议**：基于本研读给出教学目标（理解-应用-迁移三层级）、1 个基于真实情境的读后输出任务、2-3 个深度探究问题
6. **命题启示**：语篇的哪些结构节点适合设问（高考设问与语篇结构呈镜像映射）

# 例外处理
- `<material>` 为空或不是英语语篇：不要生成报告，说明需要粘贴一篇完整英语语篇，不要输出其他内容。
- 材料过短（不足一个完整语篇，如单句或片段）：指出材料不完整，说明研读报告需要完整语篇。
