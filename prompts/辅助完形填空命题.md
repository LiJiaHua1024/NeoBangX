# 任务
基于文末 `<material>` 中的英语素材（记叙文或夹叙夹议文本）命制一道高考风格完形填空题。使用者是中学英语教师。现代完形填空考查的不是局部搭配，而是语篇概括、心理推断和主题建构——设空必须让学生"读懂故事才能做对"。

# 命题规范
**文本处理**：
- 改编为 280-320 词的完整语篇，保留清晰的叙事弧线（起因 → 发展 → 转折 → 结果/感悟）
- 首段不挖空，让学生先建立语境
- 语言地道、面向高中生，不含生僻词

**设空设计（15 空，编号 41-55，A/B/C/D 四选一）**：
- 设空词汇整体构成一条**心理或概念发展线**（如 admiration → left out → unsettled → distant → shadow → worth），反映人物情绪变化、认知转变或主题深化
- 优先选择需要概括前文一段内容的抽象词（如 realization、lifestyle），而非局部搭配即可决定的词
- 埋设语篇照应：关键词或比喻的前后复现、主题句对前文的重新解释、首尾呼应
- 难度梯度：前几空偏局部语境理解，后段空需要整段概括，最后 1-2 空指向全文主题
- 设空在文中呈现为下划线加居中编号，编号前后各留两个空格，如 `___ 41 ___`

**干扰项**："形合意不合"，词性与正确项一致：重现文中高频词但逻辑脱节、符合大背景但偏离该段主题、与人物心理发展线相悖、高仿孪生选项（个别空设一对句法都通但语篇逻辑只容其一的选项）。不出靠语法即可排除的废项。

# 输出格式
Markdown，依次输出：
1. **完形填空题**（英文）：挖空后的语篇 + 15 题选项（每题一行：41. A. ... B. ... C. ... D. ...）
2. **答案表**：题号 → 答案
3. **命题说明**（中文）：这套题的心理/概念发展线是什么（列出设空词序列）；语篇照应设计在哪里；3-5 个代表性设空的干扰项策略说明

# 例外处理
- `<material>` 为空或不是英语文本：不要命题，说明需要粘贴一篇英语叙事类素材，不要输出其他内容。
- 素材是纯说明文/议论文：照常命题，发展线由"心理线"改为"概念/论证发展线"，并在命题说明中注明。
- 材料中教师指定了词数、空数或考查侧重：优先遵循教师要求。
