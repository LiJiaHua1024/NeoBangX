# 任务
基于文末 `<material>` 中的阅读课文（读写整合课）或续写素材（读后续写课），生成一份读写整合教学设计。使用者是中学英语教师。设计原理：唯有深刻，方能迁移——先深度解读课文"怎么写"（How 层面），再把解读转化为学生的写作支架，贯通读写。

# 判断分支
根据材料自动判断课型（无法判断时按分支 A 处理并注明）：
- **分支 A（读写整合）**：材料是一篇完整课文/阅读文本
- **分支 B（读后续写）**：材料是续写题（含未完成故事和段首句）

# 分支 A：读写整合教学设计
1. **文本解读（教师视角）**：
   - 提炼可迁移的语篇结构（如写人的"困难 → 努力 → 成就 → 启示"，其中困难还可拆为客观条件与自身条件两面）
   - 展示"具体化"写法：学生只会写 "He had many difficulties. He worked very hard."——对照分析课文如何把每个抽象方面写具体（动作、数字、场景、细节）
2. **读中活动**：2-3 个引导学生自己发现结构和具体化写法的问题链
3. **写作任务设计**：与课文同结构、换话题的写作任务，配四重支架——结构支架（课文结构框架图）、语言支架（课文中可迁移的词块/句型清单）、思维支架（每段的追问）、情境支架（真实交际情境）
4. **评价量表**：与结构和语言支架一致的 3-4 条评价标准

# 分支 B：读后续写教学/命题设计
遵循高考续写的稳定规律：
- 情节以"问题—解决"为核心，情感驱动强调共情与换位思考
- 两段功能分工：第一段 = 解决问题/采取行动的高潮；第二段 = 结果 + 感悟/情感升华
- 视角必须与原文一致（第一人称或第三人称有限视角）
输出：情节走向分析（原文埋了哪些伏笔线索）、两段的情节规划与心理线、语言支架（动作/情绪描写词块）、一篇 150 词左右范文（第一段体现内心转变与同理心觉醒，第二段展现具体行动与成长感悟，与前文伏笔呼应）

# 输出格式
Markdown，教学说明用中文，支架/范文/例句用英文。

# 例外处理
- `<material>` 为空：不要生成，说明需要粘贴课文原文或读后续写题目，不要输出其他内容。
