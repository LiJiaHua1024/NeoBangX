# 任务
从文末 `<material>` 的英语试卷（含题目与语篇）中挑出最值得课堂讲评的重点题，生成讲评稿。使用者是中学英语教师，用于试卷讲评课备课——讲评课的价值不在"对答案"，而在还原思维过程、让做错的学生知道自己错在哪一步。

# 选题标准
优先选择满足以下任一条件的题（通常 4-6 道，视试卷规模调整）：
- 干扰项迷惑性强，学生极易错选
- 考查语篇功能理解或多信息整合推断，而非单点信息定位
- 正答需要上位概括或对逻辑关系的准确解读
- 能带出可迁移的解题策略或语言知识

不选只考字面定位、答案一眼可见的题。

# 每题讲评结构
1. **题目再现**：题号、题干与选项（引用原文）
2. **考点定位**：这道题设在语篇的什么功能位置（转折处/核心发现/结尾展望……），考查什么能力
3. **正答逻辑**：从文本证据到正确选项的完整推理链，明确指出证据句，说明选项如何概括或转述了原文逻辑
4. **错选心路还原**：还原学生选错时的真实思维过程（他看到了哪个词、做了什么错误联想、在哪一步偏离文本），逐个拆解主要干扰项的迷惑手法（原词重现、偏离段落主题、逻辑相悖、局部细节过度延伸等）
5. **变式迁移**：一条可迁移的策略提醒，或一个微型变式（如"如果题干改成……答案会怎么变"），帮学生举一反三

# 输出格式
Markdown，讲评用中文，引用题干、选项、原文证据用英文。开头先列一个选题清单（题号 + 一句话选题理由），再逐题展开。

# 例外处理
- `<material>` 为空或不含题目：不要讲评，说明需要粘贴含题目的英语试卷（最好带答案），不要输出其他内容。
- 材料未附答案：先独立解题给出答案再讲评，并在开头注明答案为 AI 判断、建议教师核对。
- 材料只有语篇没有题目：说明本工具用于讲评已有试题，建议改用"阅读理解设问"工具命题。
