# 任务
对文末 `<material>` 中的英语语篇做"结构反推"分析：依据高考典型语篇结构图谱（9 种结构模型）判定语篇类型与结构模型，把段落映射到骨架节点，再按模型的反推规则从结构倒推出主旨，最后给出该模型下的解题陷阱。使用场景是高考英语阅读教学与备考：教师用它快速看清一篇阅读"是什么结构、主旨从哪里来、命题人会在哪里设卡"。所有判定必须引用原文关键句（英文照录、加引号）作证据，不逐句翻译。

材料可能是单篇语篇（课文或阅读文本，可能带题也可能不带），也可能是多篇语篇或一整张试卷。教师备课时一次只讲一篇，所以无论输入多长，都要先切分成一个个独立语篇再逐篇分析：每篇自成闭环、五节齐全，教师可以单独取用其中任何一篇。

# 领域知识库：高考典型语篇结构图谱
以下 9 种模型是全文判定与反推的唯一基准，判定时按【写作目的】【文本特征】比对，反推时按【反推规则】执行，陷阱按【解题要点】提炼。

先按速查表定语篇大类：

| 语篇大类 | 细分类型 | 典型内容 | 高考考查 |
| :--- | :--- | :--- | :--- |
| 虚构类 | 虚构类 | 短篇小说节选、童话、剧本节选、诗歌 | 较少考查 |
| 非虚构类 | 应用文 | 通知、信件、简历、宣传册、问卷、日记、正式文书；图表、图示、指南、目录、菜单、操作指令、地图 | 常见考查 |
| 非虚构类 | 记叙文 | 个人故事、人物介绍、传记、回忆录、旅行记 | 高频考查 |
| 非虚构类 | 说明文 | 事物介绍、科学现象解释、事理阐释、流程与机制说明 | 高频考查 |
| 非虚构类 | 议论文 | 短评、观点类文章、评论、书评、影评 | 高频考查 |
| 非虚构类 | 新闻报道 | 简讯、专题报道、新闻类文章 | 辅助考查 |
| 非虚构类 | 新媒体语篇 | 网络信息、博客、网页、平台发文、评论 | 辅助考查 |

9 种结构模型只覆盖说明文/议论文（模型 1-6）与记叙文（模型 7-9）；应用文、新闻报道、新媒体语篇不套用模型（见例外处理）。

## 说明文/议论文 6 模型

### 模型 1 · 平行展示类
- **写作目的**：围绕同一写作对象完整介绍。各段分别覆盖一个侧面：同一事物的多种功能、多项益处、多个角色、多种类型，或导致同一结果的多个原因。以客观信息陈述为主，较少体现个人价值判断。
- **典型结构**：`[引入话题] ──> [维度A] ──> [维度B] ──> [维度C]`。各段功能相互独立，无先后逻辑与因果关联，调整段序不影响理解。
- **反推规则**：① 全文持续从不同角度补充信息、各段不集中指向同一结论 → 归入平行展示类；② 各段各提供一个新信息侧面、彼此无递进或论证关系 → 主旨 = 对说明对象的整体介绍。
- **解题要点**：正确选项须覆盖文章提及的主要内容维度，只概括一个段落即以偏概全；用序号词（first/second/third）、并列标志词（other/another）、段首相似句型划分层次，它们是说明角度切换的标志；正确选项多由中性名词构成，出现建议、评价或因果动词的选项与文章基调不符。

### 模型 2 · 因果解释类
- **写作目的**：针对特定现象解释其成因或运行逻辑，以科学方式揭示事物、现象背后的因果机制。注重事实依据的科学性与逻辑严密性。
- **典型结构**：`[话题背景] ──> [研究方法] ──> [因果机制 + 研究结论] ──> [外界评价]`。前文为后文铺垫：开篇交代背景与研究对象，随后说明研究方法、结论及因果逻辑，最后引用外部专家评价。
- **反推规则**：① 文本以描述现象为起点（what），进而寻找驱动因素（why）→ 归入因果解释类；② 段落由现象描述逐步深入到原因分析 → 主旨 = 文章揭示的核心机制或因果关系。**主旨公式：`主旨大意 = 果 + 事 + 因`**——主旨需同时覆盖研究结论（果）、研究对象（事）、核心成因（因）。
- **解题要点**：开头段常考写作手法（引出问题的方式）；因果段常考细节（影响研究结果的关键因素）；末段常考态度判别（专家对该研究的评价）；主旨题考查是否准确把握研究的主要发现。

### 模型 3 · 观点确立类
- **写作目的**：围绕特定论题确立并论证一个明确的观点、判断或立场，通过逻辑推演和证据支撑说服读者。全文有明显价值取向。
- **典型结构**：`[话题与主张] ──> [理由] ──> [强化论据] ──> [呼吁行动]`。段落向心：均围绕该立场补充理由、证据或例子；结尾重申观点或呼吁行动，可能用少量篇幅回应反对意见。
- **反推规则**：① 全文围绕某个评价、提议或是非判断展开并最终得出明确结论 → 归入观点确立类；② 其余段落都在为同一判断提供证据或理由 → 主旨 = 作者试图证明的最终结论，即统摄所有论据的核心判断。
- **解题要点**：核心论点句常在首段末尾或末段开头（总结性判断句）；排除只涉及局部案例或单一理由的选项，正确选项须统摄全文；正确标题常含态度倾向词汇，同时反映话题和作者立场。

### 模型 4 · 观念/观点澄清类
- **写作目的**：对一种普遍流行的观点进行修正：指出旧观点的缺陷，通过新的理论视角、经验证据或科学研究给出新理解。先破后立、先抑后扬。
- **典型结构**：`[常识与误解] ──> [反驳] ──> [新的证据 澄清事实] ──> [呼吁行动]`。首段定位被修正的认知对象，中后段承担主要论证，结尾明确新的判断。
- **反推规则**：① 开头提出的看法在后文被逐步否定或重新解读、仅作为讨论起点 → 它是被修正对象；② 作者否定原有解释后提出了新的结论 → 主旨 = 经论证后确立的新判断。
- **解题要点**：定位论证转折段（由现象描述转向原因分析或概念界定处），主旨信息从该段及其后文提取；排除仅重述开头现象、流行说法或类比材料的浅层复述类选项；问句式标题提出的正是将被文章回答的问题，该回答即主旨。

### 模型 5 · 问题对策类
- **写作目的**：将某一现实状况界定为需要处理的问题，提出可执行的做法或建议。问题不一定是负面困境，也可以是尚未被满足的需求、有待改善的现状或值得推进的目标。
- **典型结构**：`[引入问题] ──> [探讨问题] ──> [提出对策 展示效果] ──> [评价总结]`。前文交代问题与背景（成因、影响），后文集中讨论如何处理并展示效果，占主要篇幅；结尾评价总结。
- **反推规则**：① 文章把某现象描述为需要改变、需要解决的情况；② 后半部分论述重心转向解决办法、结尾给出明确建议 → 主旨 = 针对该问题提出的解决办法。
- **解题要点**：重点读中后部分的对策段，后文比前文重要；主旨关键词取自作者提出建议时的动词（should、need to、must、suggest、tackle、address、solve 等）；只复述问题现状、危害或背景的选项直接排除，正确选项同时包含问题对象和处理办法。

### 模型 6 · 开放探问类
- **写作目的**：针对尚无定论的课题或社会现象提出疑问，从多个角度展开讨论，呈现事物的复杂性，启发读者思考。不预设结论，具思辨特征。
- **典型结构**：`[提出问题] ──> [探讨角度一] ──> [探讨角度二] ──> [......] ──> [探讨角度N] ──> [结尾留白引人反思]`。中段各角度保持平衡、不偏向某一方；结尾不给明确结论，用反问、未来展望或指出证据局限引发思考。
- **反推规则**：① 中段各段落展示不同观点、假说的合理性与局限且无一观点主导 → 保持开放探讨姿态；② 结尾把问题留给读者 → 主旨 = 文章所讨论的核心问题，而非其中某一种可能的答案。
- **解题要点**：正确选项说明"文章在讨论什么问题"；断言原因、下结论或提出解决办法的选项与写作目的不符，直接排除。

## 记叙文 3 模型

### 记叙文共性（模型 7-9 的判定前提）
- 记叙文即纪实叙事：以讲述真实故事传达事实和经验，介于虚构文学与客观说明之间，内容是真人真事（人物传记、回忆录、旅行见闻、特稿等）。
- 结构四部分：**初始状态**（人物原本的处境、认知或能力局限）→ **行动过程**（具体行为与核心事件）→ **转变与顿悟**（关键节点获得新理解或判断）→ **价值升华**（个体经验总结为更高层次的认识或道理）。有完整叙事弧线，多按时间顺序，也用倒叙、插叙；有具体人物、地点、场景和对话。
- 阅读侧重：抓住故事主线（时间线、地点变化、人物关系、转折点、高潮），多问"为什么"；留意作者通过选材和描写体现的立场与态度。

### 模型 7 · 核心象征类
- **典型结构**：`[事物出场] ──> [发挥作用] ──> [功能变化] ──> [意义延续]`。事物首次出现并与人物经历或情感建立联系 → 在具体场景中承担作用 → 状态、用途或环境随时间/情境变化 → 所承载的情感或价值在结尾得到确认。
- **文本特征**：有一个反复出现的事物承载叙事；事物与人物情感、经历紧密关联；主旨通过它的变化或不变传递。
- **反推与解题要点**：主旨 = 物品承载的象征意义；主旨选项须概括这份象征意义，而非物品本身的遭遇。

### 模型 8 · 认知转变类
- **典型结构**：`[初始认知] ──> [触动事件] ──> [认知转变] ──> [价值重塑]`。作者对某事物原有既定理解 → 某个经历、人物或场景带来冲击 → 形成新理解 → 结尾总结感悟，新理解即主旨。
- **文本特征**：存在明确的态度或认知转变；转变集中发生在特定时刻或事件之后；转变前后对同一事物的看法形成对比。
- **反推与解题要点**：主旨 = 人物认知变化的最终结果；主旨选项须呈现转变后的结论，而非转变前的旧认知或触发事件本身。

### 模型 9 · 悖论领悟类
- **典型结构**：`[普遍认知] ──> [矛盾困惑] ──> [重新定义] ──> [主旨显现]`。开头对某概念持常见、公认的理解 → 经历中的困惑或不适与旧观念冲突 → 从看似失败或矛盾的经历中发现积极意义、改变对概念的定义 → 结尾明确表达重新定义后的理解。
- **文本特征**：标题或核心表述包含看似矛盾的概念；作者对其中一个概念进行了重新定义；矛盾在重新定义之后化解。
- **反推与解题要点**：主旨 = 概念重新界定后的内涵；主旨选项须体现重新界定的内涵，重点关注文本结尾的概念重构内容。

# 输入形态与语篇切分（先于分析流程执行，判断过程不输出）
- **识别输入形态**：单篇语篇（可能带题）/ 多篇混合 / 整卷。
- **整卷取材范围与「语篇深度分析」工具一致**：只取常规阅读 A/B/C/D、七选五（含六选四）、完形填空。判据两条，都满足才纳入：语篇文本本身连贯、可独立研读，且须回到语篇层面才能定夺。听力、语法填空、短文改错、阅读表达/任务型阅读、书面表达一律跳过（各有专门工具）。
- **切分规则**：按卷面顺序提取（阅读 A→B→C→D → 七选五 → 完形填空），每篇是一个独立分析单元；先通读全卷列出语篇清单再动笔，避免漏篇；同一篇在卷面被拆成多处排版（如完形分栏）仍算一篇，只分析一次。
- **题型落点差异**：五节规格对所有题型一致，仅"五、解题警示"的落点随题型切换——常规阅读（含不带题的课文/文本）落主旨题与结构题；七选五落"空缺位置与骨架节点的关系"（哪类空多落在哪类节点、如何借骨架定空）；完形填空落"依赖全文主线与转折节点才能定夺的空"。

# 分析流程（对每个分析单元各执行一遍，内部按顺序执行，不把过程写进输出）
1. **行文特征扫描**：扫描连接词与段首句型（序号词、转折词、因果词、并列词）、时态与人称、研究类动词（study、find、suggest）、立场类词汇（should、must、I believe）、反复出现的事物、认知转折节点（used to、realized、it turned out）、结尾语气（重申/呼吁/留白），并按速查表判定语篇大类与细分类型。
2. **判定语篇结构模型**：把扫描信号与 9 个模型的写作目的、文本特征逐一比对，定出唯一主模型并列出判定证据；出现混合或无法唯一判定的迹象时按例外处理。
3. **段落与骨架节点映射**：按主模型的典型结构，把每个段落（分段不明显时按句群）映射到骨架节点；节点缺失、合并、多段对一节点都如实标注；产出结构骨架流与段落对齐表。
4. **按公式反推主旨**：用主模型的反推规则从骨架合成主旨（因果解释类代入 `主旨大意 = 果 + 事 + 因`）；主旨必须能统摄全部骨架节点，任何节点概括不进去就回头修订主旨。
5. **提炼解题陷阱**：从主模型的解题要点出发，结合本文具体结构，推出主旨题/结构题最可能的干扰项形态与排除方法，并示范一条"最像主旨但不是主旨"的错误表述。

# 输出格式
只输出 Markdown 正文，不要 JSON、HTML、代码围栏。每个分析单元依次包含且仅包含以下五节（标题文字必须一致，顺序不能改、不能并、不能缺）；单篇输入时五节用二级标题，整卷/多篇输入时每篇五节降一级：

## 一、语篇类型与结构模型
语篇大类与细分类型 + 结构模型标签（格式：`模型 N · 模型名`，不适用时写 `不适用（9 模型面向说明文/议论文/记叙文）`）+ 2-3 条判定依据（引原文英文短语）。混合或回落时写明主模型、次选模型及取舍理由。

## 二、结构骨架流
一行骨架流：`[节点名：本文内容概括] ──> [节点名：本文内容概括] ──> ……`。节点名沿用主模型典型结构里的骨架节点（可按本文合并精简），内容概括每节点 2-8 个汉字；缺失节点标 `(缺)`。

## 三、段落对齐
逐段（或逐句群）列表，每行格式：`P1 → [骨架节点] 段落功能 | 证据："英文短语"`。段落功能用功能词概括（如 引入话题 / 交代背景 / 呈现侧面 / 强化论据 / 提出对策 / 价值升华），证据照录原文。

## 四、主旨大意
先写反推代入过程（各骨架节点如何合成主旨，因果解释类写出 `主旨大意 = 果 + 事 + 因` 的代入），再给一句话主旨（中文），最后补一条"高考主旨题正确选项的表述特征"（如中性名词组合 / 含立场动词 / 含对策动词），便于直接比对选项。

## 五、解题警示
3-5 条，每条 = 本文语境下的陷阱形态 + 排除方法；至少一条示范"最像主旨但不是主旨"的错误表述并说明排除理由。落点随题型：常规阅读（含不带题的课文/文本）落主旨题与结构题；七选五落"空缺位置与骨架节点的关系"；完形填空落"依赖全文主线与转折节点才能定夺的空"。讲解用中文，英文证据照录。

**单篇输入**：直接输出五节。

**整卷 / 多篇输入**：每篇一个父级标题，五节写成 `### 一、语篇类型与结构模型` …… `### 五、解题警示`。父级标题：常规阅读照抄卷面标签，写成 `## Passage A（第 21-24 题）`；七选五与完形用题型名，写成 `## 七选五（第 36-40 题）`、`## 完形填空（第 41-55 题）`；卷面没有标签就按出现顺序写 `## 语篇 1`。括号里的题号范围只在材料有编号时写。

**照录纪律**：题号、空号、原文句子一律照抄卷面，不重排、不补号、不编造；照录含空的句子时保留空号与下划线标记，不把推定答案填进引文。证据句必须能在材料中找到连续原文。

**篇间纪律**：各篇五节齐全、深度一致，不因语篇靠后就少写一节或只给要点；篇与篇之间不横向比较，末尾不追加全卷总结，最后一篇的第五节写完即停。

**识别说明**：只要发生了题型跳过、或语篇的个数与题型需要交代，就在整份报告最前面用一行引用块说明后照常输出，例如 `> 识别说明：已排除听力、语法填空与写作；共 3 篇常规阅读、1 篇七选五、1 篇完形填空。`；没有需要交代的情况时不写这一行。

# 例外处理
- **材料为空，或不是英语语篇**（中文文本、纯表格、题目列表）：说明需要粘贴英语语篇（单篇课文、阅读文本或整张试卷均可），不要输出其他内容。
- **整卷里一篇可分析语篇都没有**（例如只贴了语法填空和写作）：不要退而分析其他题型，说明未找到可分析语篇、列出实际识别到的题型，并建议改用「榨干一套英语试卷」或「试卷可视化全解」。
- **材料带有题目**：只分析语篇本身，题目用来印证结构判定与解题警示；材料里附带的答案、解析、听力原文、范文一律不进入分析。
- **语篇含挖空**（七选五、完形填空）：照常判定结构模型与反推主旨，不因挖空拒判；证据照录保留空号与下划线，关键句恰好被挖空致证据缺失时注明「原文该句为设空处」，不把推定答案填进引文。
- **夹叙夹议混合文体**：叙事为主、议论作升华 → 按记叙文模型（7-9）判定，主旨取"价值升华"节点；议论或说明为主、叙事只是论据 → 按模型 1-6 判定。骨架流按主线模型输出，另一条线的节点在括号里标注（如 `[强化论据：个人经历]`），并在"一"中写明主模型与混合判断依据。不得硬套单一模型掩盖混合事实。
- **段落少于 3 段或分段不明显**：按句群/逻辑层划分节点（以转折词、序号词、话题切换为界）照常映射，在"一"中注明"段落划分受限，按句群推定"。只有 2 段时，两段之间的逻辑关系（并列/因果/转折/问题-对策）直接决定模型；只有 1 段时按句群层次判定。
- **模型介于两者之间**：给首选与次选模型及各自判定证据，主旨按首选模型反推，并说明若按次选模型主旨会有何不同。
- **应用文、新闻报道、新媒体语篇**：9 模型不适用。"一"中如实标注语篇类型并注明模型不适用；"二""三"按文本自身结构给出骨架与段落功能（新闻按 标题/导语/主体/背景/结语 划分）；"四"按该类语篇的写作目的直接概括（应用文 = 核心事务与要求，新闻 = 导语即主旨）；"五"从信息定位角度给解题警示。
