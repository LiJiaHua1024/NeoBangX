# 任务
基于文末 `<material>` 中的阅读文本，设计一节完整的英语阅读课。使用者是中学英语教师。一节阅读课最重要的三个地方是：**文本解读、支架搭建、读后输出活动设计**——方案的质量取决于这三处，环节流程只是载体。

# 设计要求

**1. 文本解读（备课底座）**：
- What：核心内容与主题语境
- Why：写作意图与主题意义（一句话点透语篇本质，如《当哈姆雷特遇上京剧》的本质是 "Beyond the familiar: why you should experience art in a new light"——只有点到这个层面，深度学习才会发生）
- How：语篇深层结构（如 PSR：problem-solution-result、before-transformation-after、起承转合）与语篇标记词

**2. 教学目标**：用 SOLO 分类理论设"理解 → 应用 → 迁移"三层级目标，每层可观测、可评价。

**3. 教学过程**（读思言路径：输入 → 内化 → 输出）：
- **读（导读/细读/检读）**：导读创设情境激发兴趣；细读安排持续独立的默读与信息梳理批注；检读用问答/填表检验整体理解。借班上课式的稳妥做法：让学生读后填关键词或填表，教师对学生"照本宣科式"回答做上位提炼和语言转述升级
- **思（结构化/词义化/循证化）**：问题链引导学生自己发现语篇结构；关键词提取与上位概括；基于文本证据的推理思辨。设计 1 个深度对话探究议题
- **言（创境/创生/创评）**：创设真实表达情境，搭建支架后开展以读促说/写。支架必须四重齐备——结构支架（从文本解读中来）、语言支架（文中可迁移词块/句型）、思维支架（追问链）、情境支架（真实交际情境）

**4. 评价设计**：与目标一致的评价任务和简易量表（教学评一致性；自评/互评/师评结合）。

# 输出格式
Markdown，方案用中文，问题链/支架/任务指令用英文。依次输出：文本解读 → 三层级目标 → 教学过程（读/思/言各环节含活动目的、操作步骤、支架内容、预计用时）→ 评价设计。

# 例外处理
- `<material>` 为空或不是英语文本：不要生成，说明需要粘贴阅读课文本，不要输出其他内容。
- 材料附带了学情说明：按学情调整任务难度和支架密度。
