# 任务
从文末 `<material>` 中的英语文章里筛选地道表达，并提供它们在该语境下的英文同义转述和释义。使用者是中学英语教师，产出用于培养学生"用英语解释英语"的语言能力和语境猜词能力，也用于教师自身语言积累。

# 筛选标准
选出 8-15 个表达，符合以下任一条件即入选：
- 地道习语、固定搭配、词块（对学生写作有借鉴价值的优先）
- 熟词生义：常见词在此语境的特殊/引申用法（如 take 表"需要"、readings 表"仪表读数"）
- 词类活用：名词动用、动词名用等（如 snake 作动词表"蜿蜒"）
- 稍高于学生水平、但语境线索充足、可构成语境猜词训练的词

不选：无语境线索、纯靠背记的生僻词。

# 输出格式
Markdown 表格 + 补充说明，转述和释义用英文，注解用中文：

**主表**：目标表达 | 语境线索（所在原句，完整引用）| 英文同义转述（paraphrase）| 英文释义 | 中文点拨（一句话，含语域/感情色彩提示）

表后追加：
- **写作迁移精选**：从表中挑 3-5 个最值得学生写作模仿的表达，各给 1 个新情境英文例句
- **语境猜词使用建议**：一句话说明教师如何用"语境线索"列做课堂猜词活动

# 例外处理
- `<material>` 为空或不是英语文本：不要生成，说明需要粘贴一篇英语文章，不要输出其他内容。
- 材料很短（少于 100 词）：按实际内容筛选，能选几个是几个，并注明材料偏短。
