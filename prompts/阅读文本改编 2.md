# 任务
把文末 `<material>` 中的英语文本改编为体现"词汇考查真实化转向"的高考阅读风格文本。使用者是中学英语教师。与常规简化式改编相反，本工具的目标是：难度不来自生僻词，而来自基础词的地道组合与灵活活用——把"词的陌生"转向"熟词的陌生组合"。

# 改编标准
- **词数**：约 320 词（300-340 之间），保持语篇结构完整、逻辑链清晰。
- **词汇真实化改造**，从三个维度注入原汁原味的表达：
  1. **地道词块**：用基础词组成的地道短语替换平淡表达，如 hit home（使人深切意识到）、stick the landing（把结尾收稳）、weed out（筛除）、sink in（被理解内化）、set sb up for（为将来做准备）
  2. **词性活用**：名词动用、动词名用等，如 stand 作名词指摊位、model 作动词指示范、cover 作动词指讲授、spot 作动词指发现、power 作动词指驱动
  3. **合成词与连字符表达**：如 go-to destination、headline-grabbing、color-coded、dog-friendly、jaw-dropping
- **同义替换**：全文避免同一词汇重复，用地道的同级替换，如 review → write-up、problem → issue/challenge/concern、help → aid/enable/support、change → shift/transition、good choice → sure bet。
- **语体色彩**：改造后的表达要与原文语体匹配（媒体语体、现代口语色彩、幽默评价等），不能只替换词汇不管语域。
- **底线约束**：所有改造用的都是高中生认识的基础词，不引入真正的生僻词；不替换承载特定文化内涵的词；每处改造后上下文必须足以支撑词义推断。

# 输出格式
Markdown，依次输出：
1. **改编后文本**（英文，标注实际词数）
2. **词汇改造清单**（中文表格）：原表达 → 改造后表达 | 类型（词块/活用/合成词/同义替换）| 语境含义 | 命题价值（可考什么）
3. **命题建议**（中文，3-5 行）：哪些改造点适合出词义猜测题或用于完形设空

# 例外处理
- `<material>` 为空或不是英语文本：不要改编，说明需要粘贴一篇英语文本，不要输出其他内容。
- 原文已经高度地道（如外刊原文）：以结构调整和词数控制为主，改造清单改为标注原文中已有的真实化词汇考查点。
- 材料中教师附加了具体要求：优先遵循教师要求。
