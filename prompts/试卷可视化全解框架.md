# 任务与意图

程序已经拿到整份英语试卷（见文末 `<material>`，每行带行号），你的任务是在正确的位置插入结构标记，告诉程序语篇从哪开始、每道题从哪开始、选项从哪开始、答案区从哪开始，程序按标记把原文切成 语篇/题干/选项/答案区，最终生成课堂课件。标记插错位置 = 题干切错 = 课件直接出错。

原文内容一个字都不需要你输出：你只输出标记指令，每条指令带一小段「锚点」原文供程序定位。

# 输入格式

`<material>` 中每行格式为 `行号 | 原文`。行号只是帮你定位的参照；锚点抄的是原文本身，**不含行号前缀和竖线**。

# 输出契约

全部输出都是单行指令，一行一条，不写 JSON、不写解释、不输出原文内容。共两类：

**第 1 类：文件头（最先输出，各一行）**

```
@@TOTAL@@ 25
@@PAPER@@ 2022年普通高等学校招生全国统一考试（全国甲卷）英语
```

- `TOTAL` = 笔试题总数（跳过听力，含写作题），整数。
- `PAPER` = 卷首标题，照卷面抄一行以内；卷面无标题就写年份+科目的合理名称。

**第 2 类：插标指令（严格按试卷行文从上到下输出）**

```
@@MARK 类型 参数@@ 锚点
```

- 锚点 = 从原卷**逐字**抄的一小段文字（通常是目标行行首的一小句；若要切的点在行中间，就从行中那个位置抄起）。
- 程序从上一个标记的位置向后搜索锚点，在它**前面**插入标记。锚点落在行中间时，程序会在该处把这一行断开——这正是切分「语篇末尾和题号挤同一行」的方法。
- 锚点必须逐字抄写（含大小写、标点、撇号）；程序找不到锚点就把这条指令整个丢弃。

六种标记，参数与锚点用法各不相同：

| 标记 | 参数 | 锚点位置 | 作用 |
|---|---|---|---|
| `@@MARK GROUP id|标题@@` | 板块代号\|组标题 | 该组语篇正文第一行（详见下文分组规则） | 声明一组开始，其后到下一组之前的题都属于它 |
| `@@MARK PASSAGE P1@@` | 语篇编号 | 语篇正文第一行行首 | 声明语篇开始，之后的正文属于该语篇 |
| `@@MARK Q 24@@` | 题号 | 题目那一行的题号处 | 声明一道题开始，之后的文字属于题干 |
| `@@MARK Q 56-65@@` | 题号区间 | 语篇正文任意一行 | 批量声明「空在语篇里」的题（见下） |
| `@@MARK OPTIONS@@` | 无 | 第一个选项行的选项字母处 | 声明选项开始，之后的行是选项 |
| `@@MARK OPTIONS 36-40@@` | 共用题号区间 | 选项池第一行行首 | 共享选项池（七选五），程序给每空生成一块 |
| `@@MARK KEY@@` | 无 | 卷末答案/解析区第一行行首 | 圈出答案区，供讲解模型核对答案 |
| `@@MARK CUT@@` | 无 | 应丢弃文字的首行行首 | 此处提前结束上一区域，其后内容按噪声丢弃 |

GROUP 的板块代号只允许：`reading`（阅读理解）、`cloze7`（七选五）、`cloze`（完形填空）、`grammar`（语法填空/短文填空/短文改错）、`writing_app`（应用文写作）、`writing_cont`（读后续写）、`other`。组标题写中文（如 `阅读理解 A篇`、`语法填空`）。

# 什么时候发哪条标记（每道笔试题都要覆盖到）

- **一个语篇一组。** 分组的依据只有语篇：组是课堂上的讲题单元，全组的题共享同一篇语篇，老师过完这一篇再过下一篇。所以数一数卷面有几篇**要作答的**语篇，就发几条 GROUP——阅读理解的 A、B、C、D 篇是四组（id 都写 `reading`）；七选五、完形填空、语法填空整卷只有一篇，就各是一组，15 个空放进同一组完全正常；写作每个板块一组。
- **标题在有歧义时才编号。** 编号（A篇/B篇、第1篇/第2篇）的作用是区分同类里的多篇语篇：同一题型下有多篇才需要它——卷面印了篇标就照抄（`阅读理解 A篇`），没印就自己编号（`阅读理解 第1篇`、`第2篇`）。同一题型下只有一篇时直接写题型名（`完形填空`、`语法填空`、`七选五`）：此时编号不消除任何混淆，「语法填空 第1篇」只会让老师以为还有第2篇。
- **不按空位把一篇语篇拆成多组。** 组跟着语篇走而不是跟着题号段走：完形填空 15 个空共享一篇语篇，按空号中段把同一篇拆成两个组，讲解就被切成两段，而组与组的边界处没有任何语篇变化——没有信息增益，只有割裂。
- 每组开始处发一条 GROUP，**锚点必须落在该组第一道题的标记位置处或之前**：程序把 GROUP 锚点之后的第一道题归入该组，GROUP 落到题号之后就归错组、留下空组。分两种情况：
  - 语篇印在题目之前的题型（阅读、完形、七选五、语法填空）：GROUP 与 PASSAGE 同锚在该组语篇正文第一行（篇标是单独一行字母时也锚在正文第一行——单字母做锚点程序会拒收）。
  - 写作板块：要求行印在材料之前，GROUP 与该组第一题的 Q 同锚在要求行行首。**应用文写作与读后续写是两个独立的组**（id 分别为 `writing_app`、`writing_cont`），各发一条 GROUP——即使卷面把它们印在同一节里。
- 每篇语篇的第一行前发一条 PASSAGE，编号按出现顺序 P1、P2……；同一篇语篇只发一条。
- 语篇正文结束后、下一道题开始前的说明文字（如「阅读下列短文，从每题所给的A、B、C、D四个选项中…」），在它行首发一条 CUT——否则这些说明会被并进语篇正文。
- 每道**卷面上印了题干行**的题：发一条 Q，锚点从该行题号处抄起（题号在行首就从行首抄；题号在行中就从题号抄）。紧随其后的选项行，在第一个选项的字母前发一条 OPTIONS。
- 语法填空、短文填空这类**空在语篇里、卷面没有独立题干行**的题：先发该语篇的 PASSAGE 标记，再发一条区间 Q（如 `@@MARK Q 56-65@@`，锚点用语篇正文任意一行）。区间声明不会切断语篇；程序会在语篇正文结束后生成各空对应的题。
- 七选五：语篇照常发 PASSAGE；语篇后的共享选项池发区间 OPTIONS（如 `@@MARK OPTIONS 36-40@@`，锚点在选项池第一行行首），空号区间按卷面空格编号写。
- 完形填空若卷面把每空的选项印成独立行（如 `21. A. hoped B. wanted ...`）：每行发一条 Q + 一条 OPTIONS，两者锚点相同（都从该行行首抄）。
- 读后续写的材料也是一篇语篇：Q 锚在「阅读下面材料…」的要求行行首，PASSAGE 锚在故事原文第一行行首——故事原文与两段开头语都属于该语篇，程序会把它们挂回本题展示。应用文写作没有语篇材料，不发 PASSAGE（程序按「无独立语篇」处理）。
- 卷末的参考答案区（答案表、答案与解析、范文）：在其第一行行首发一条 KEY。
- 听力部分（听力对话、播放说明、听力题干与选项）一律不发任何标记——程序会自动丢弃未标注的噪声，这正是跳过听力的方式。
- 题号规则：卷面印了题号就照抄数字本身（`24.`、`24、`、`(24)` 都写 `24`）；卷面没印题号的题（写作板块常只印"第一节/第二节"）接着上一题顺延编号。`TOTAL` 必须等于你发出的题目总数。

# 边界情况示例（这些是最容易错的情形）

**例 1：语篇末尾和题号挤在同一行**——Q 锚点从行中题号处抄起：

```
原文第 5 行：And you'll never be without something to read. 24. Why did BART start the kiosk program?
@@MARK Q 24@@ 24. Why did BART start the kiosk program?
```

程序会在此处断行：前半句留在语篇里，`24. Why did…` 开始成为题干。

**例 2：题干和选项挤在同一行**——OPTIONS 锚点从选项字母处抄起：

```
原文第 8 行：24. Why did BART start the kiosk program? A. To promote the local culture.
@@MARK Q 24@@ 24. Why did BART start
@@MARK OPTIONS@@ A. To promote the local culture.
```

**例 3：完形填空的选项行自带题号**——Q 与 OPTIONS 同锚：

```
原文第 12 行：21. A. hoped  B. wanted  C. expected  D. meant
@@MARK Q 21@@ 21. A. hoped
@@MARK OPTIONS@@ 21. A. hoped
```

**例 4：语法填空（空在语篇里）**——先 PASSAGE 后区间 Q，锚点用语篇内任意一行：

```
@@MARK PASSAGE P3@@ Reading below is a passage with blanks
@@MARK Q 56-65@@ Reading below is a passage with blanks
```

**例 5：七选五的共享选项池**：

```
@@MARK OPTIONS 36-40@@ A. Making a choice
```

**例 6：阅读理解按篇分组**——A、B 篇各自一组，GROUP 与 PASSAGE 同锚在正文第一行：

```
@@MARK GROUP reading|阅读理解 A篇@@ Most people ride BART every day
@@MARK PASSAGE P1@@ Most people ride BART every day
@@MARK Q 21@@ 21. ...
（A 篇的题与选项照常）
@@MARK GROUP reading|阅读理解 B篇@@ Last month, our school held
@@MARK PASSAGE P2@@ Last month, our school held
```

**例 7：整卷只有一篇的题型直接用题型名**——完形 15 空同组，标题不带篇号（只有一篇，「第1篇」无歧义可消）：

```
@@MARK GROUP cloze|完形填空@@ On a cold winter morning, I left
@@MARK PASSAGE P3@@ On a cold winter morning, I left
（41-55 空的选项行照常逐行发 Q + OPTIONS，全部落在这一个组里）
```

# 硬规则（违反即作废）

- 锚点逐字抄写原卷文字，含标点与大小写；每条锚点保持简短但**至少 3 个字符**（单个字母/数字做锚点会误配，程序直接拒收）。
- 锚点按试卷从上到下的顺序定位：每条指令的锚点必须出现在上一条锚点之后。输出顺序即试卷顺序。
- 你只输出指令，不输出原文正文、不输出语篇、不输出题干选项的内容——内容由程序从原卷提取。
- 题目总数与 `TOTAL` 对得上；每道笔试题恰好对应一条 Q 或一条区间 Q；不漏题、不并号。
- 指令独占一行；不要输出 JSON、Markdown 代码围栏、解释性文字。
