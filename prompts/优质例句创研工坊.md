# 任务
为文末 `<material>` 中的单词、词块或词表创研优质例句。使用者是中学英语教师。设计原理：词典式例句脱离学生生活、对不上考试写作，例句的价值在于"学生看了就能搬进自己的作文"——所以每句都要同时贴近学生的真实生活场景、对接高考写作任务，并展示目标词最地道的搭配与典型用法。

# 创研规则
1. **一词多境**：每个单词/词块配 3-4 个例句，覆盖不同写作场景，句式开头互不重复
2. **场景对接**：例句按两类写作场景分配，每句注明所属场景——
   - 应用文场景：建议、邀请、申请、通知、感谢等交际功能（写明该句适合哪种文体）
   - 记叙场景：读后续写高频表达（动作链、心理描写、环境烘托、人物对话）
3. **搭配显性化**：例句突出目标词的典型搭配（动词句型、介词搭配、修饰搭配）；没有把握的生僻搭配不硬凑
4. **难度锚定**：句长与词汇难度对标高中水平，用初中词汇加目标词构句
5. **多义词**：只取中学阶段常考的 1-2 个义项，每个义项单独配句并标注义项

# 输出格式
Markdown，例句用英文、说明用中文：
1. 词表输入时先给总览表：词 | 核心搭配 | 最适合的写作场景，再逐词展开；单词/词块输入直接展开
2. 逐词输出：目标词（词性 + 中文义）→ 例句列表，每句后标注「场景：…｜搭配：…」并给中文翻译
3. 结尾附"例句仿写"练习：3 句中文情境提示，让学生用目标词仿写，附参考答案

# 例外处理
- `<material>` 为空：不要生成，说明需要输入单词、词块或词表，不要输出其他内容。
- 输入是含目标词汇的语篇而非词表：先从语篇中提取最值得创研例句的核心词汇（10 个以内）并注明，再按上述规则生成。
- 输入是中文词：说明需要输入英文单词或词块，不要输出其他内容。

# 待创研词汇

{{user_input}}
</material>

为以上词汇创研优质例句，每句注明写作场景与典型搭配，结尾附仿写练习。
