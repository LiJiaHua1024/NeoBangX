# 任务
为文末 `<material>` 中的英语语篇一次性命制**两个独立版本**的高考风格阅读理解选择题（版本 A、版本 B，各 4 题），供教师对比鉴别、择优采用或交叉拼合。使用者是中学英语教师——同一语篇的设问方案不唯一，两个版本能帮教师看清不同设问路径的取舍。

# 命题规则（两个版本共同遵守）
- **镜像映射**：设问分布与语篇结构对应——先分析语篇的功能框架（引入 → 展开 → 转折/发现 → 收束），再让题目落在这些关键功能节点上，不问孤立细节。
- **正确选项**：基于文本证据的合理推断，用上位概念概括原文信息，关键词精准外显文本逻辑；不做原文的机械同义替换。
- **干扰项**："形合意不合"——表面词汇陷阱、偏离段落核心主题、与主旨/态度逻辑冲突、局部细节过度延伸。
- **选项语言**：简洁、结构相近、长度大致相等。
- 每版最后一题为主旨大意或最佳标题题。

# 两个版本的差异化要求
两版不是同一套题的措辞微调，必须在命题路径上真正不同：
- **版本 A（标准化取向）**：信息覆盖面广、多点取样，题目分布均匀覆盖各段，侧重实证细节的因果与推断，答案唯一性强、可测量性好
- **版本 B（综合思辨取向）**：设问更集中于语篇的核心矛盾或深层意义，侧重态度立场、写作意图、信息价值的抽象概括，综合性强

同一个文本位置两版都设题时，设问角度必须不同。

# 输出格式
Markdown，依次输出：
1. **语篇结构速览**（中文，3-5 行）：功能框架与可设题的关键节点
2. **版本 A**：4 题（英文）+ 逐题答案与一句话证据（中文）
3. **版本 B**：4 题（英文）+ 逐题答案与一句话证据（中文）
4. **鉴别指引**（中文表格）：逐一对比两版对应题目——考查能力、难度、区分度预判、各自的强项与风险，最后给出择优或拼合建议

# 例外处理
- `<material>` 为空或不是英语语篇：不要命题，说明需要粘贴一篇英语语篇，不要输出其他内容。
- 语篇过短（不足 150 词）：每版减为 2-3 题并注明。
- 材料中教师指定了题量或侧重：优先遵循教师要求，但仍保持两版差异化。
