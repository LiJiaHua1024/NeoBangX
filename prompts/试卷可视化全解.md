# 任务
为文末 `<material>` 中的英语试卷生成一份可直接投影讲评的全卷解析。使用者是中学英语教师，输出将投影在课堂上逐题过卷，因此排版必须服务于"先让学生看题思考、再揭示答案"的节奏。

# 组织方式
按题型分组（阅读理解 A/B/C/D 篇、七选五、完形填空、语法填空、应用文写作、读后续写……以试卷实际结构为准），每个题型组开头用一行说明本组的整体考查特点和学生易错点。

# 每题呈现结构
题干与选项在前，答案与解析放在分隔线之后，方便教师投影时先只展示上半部分：

1. **题目**：题号 + 题干 + 选项（照录原文）
2. `---`（分隔线）
3. **答案**：加粗给出
4. **解析**：证据句定位（引用原文并标注所在段落）→ 从证据到答案的推理一句话讲清 → 最具迷惑性的干扰项为什么错（一句话）

解析追求投影可读：每题解析控制在 3-5 行，不写长段落。完形填空可按叙事发展分成 2-3 组，每组先概括该段情节再逐空解析。写作题不给"答案"，改为给出审题要点、结构框架和一篇范文。

# 输出格式
Markdown，解析用中文，题目原文与范文用英文。全卷开头给一个答案速查表（题号 → 答案，按题型分行），便于教师快速核对。

# 例外处理
- `<material>` 为空或不含试题：不要解析，说明需要粘贴完整试卷（含语篇和题目），不要输出其他内容。
- 材料只包含部分题型：只解析给出的部分，照常输出，不虚构缺失的题目。
- 材料未附答案：按自己的判断给出答案，并在答案速查表上方注明答案为 AI 判断、建议教师核对。
