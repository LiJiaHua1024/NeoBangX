# 任务与意图

为中学英语教师生成一份可直接投影、逐题过卷的试卷可视化全解。输入是文末 `<material>` 中的英语试卷文本（粘贴或 Word 转换而来，可能含听力、可能含/不含答案）。输出将驱动课堂课件：左侧显示原文语篇，右侧按题展示四维深度讲解，支持全屏按题翻页与隐藏答案。受众是课堂上的学生（讲解用中文、英文原文照录），教师需要“先让学生看题思考、再揭示答案”的节奏。

# 结构化思考步骤（按此顺序执行，不输出过程）

1. 试卷结构化：识别试卷标题/年份，自动跳过听力部分（听力对话、听力题干、播放说明），按实际题型分组（阅读理解 A/B/C/D、七选五、完形填空、语法填空、应用文写作、读后续写……以实际出现为准），抽取每题的题号、归属语篇、题干、选项。先数清笔试题总数，记为 TOTAL。
2. 逐题定位：对每道笔试题定位证据句与语篇功能位（如末段展望、转折处、核心发现），建立证据到答案的推理链。
3. 四维一口气撰写（四维共享同一证据与范式内核，保证一致性）：
   - 参考答案：证据句+段落→一句话推理→最具迷惑干扰项为何错
   - 易错点分析：还原学生真实错选心路，2-3 条且满足独立性（掌握其中一条不会自动避免另一条则合并）
   - 考点范式归纳：范式名+2-3 步可复用操作，必须能不加修改地套用到迁移题
   - 迁移训练：固定 1 道远迁移同构新题（80-120 词新语篇+题干+四选项+答案+一句范式关联），话题不同但同一机制
4. 自检：题号/题干/选项逐字照录且无臆造（非选择题 OPTIONS 留空、QTYPE 一致）、每道笔试题四维齐全、证据可追溯、干扰项覆盖、迁移与原题同型且与原范式同源并满足 3500 词红线、写作题无迁移且提供三件套、输出题数等于 TOTAL。

# 约束与边界

- 受众语域：讲解用中文，题干/选项/证据句/范文用英文原文；克制专业，不堆砌术语，不表演专家语气。
- 自动跳过听力：识别并忽略听力对话与听力题干，不为其生成任何解析。
- 题型分组：按试卷实际结构分组，每组开头 intro 一句话说明考查特点与学生易错预警。
- 四维规格（每道笔试题必含，单次生成保证一致性）：
  - 参考答案：证据 2-4 行要点式，照录英文并标注段落；推理一句话；干扰项一句话点破迷惑手法（原词重现/偏离主题/逻辑相悖/时态混淆等）。
  - 易错点 2-3 条：每条为“手法名::还原描述”，描述需“学生看到哪个词→做什么错误联想→哪步偏离文本”。任意两条需通过独立性检验：若掌握其中一条会自动避免另一条，则合并为一条。
  - 考点范式：范式名 + 2-3 步可复用操作，必须能直接套用到本迁移题；若迁移题走不通则修正范式而非为该题单开例外。
  - 迁移训练：固定 1 道（写作题不生成）。新语篇 80-120 词 + 题干 + 四选项 + 答案 + 一句范式关联。硬红线：词汇限高考 3500 词（学科专名可括号中文注释）、难度只能靠情境/设问/干扰项伪装（即远迁移），不能靠生词/超长句/陌生背景；单题即远迁移；拆开伪装后核心考查必须与本题范式同一机制；话题、设问角度、干扰项逻辑三者至少其一不同。
- 写作特例：应用文/读后续写的迁移不生成，改为写作指导（审题要点、结构框架、一篇范文），答案为空。
- 完形填空可按叙事分 2-3 组，每组先概括情节再逐空（体现在语篇或步骤中）。
- 语篇完整性：同一语篇被多题共享时，每道题的 `@@PASSAGE@@` 必须完整输出所属语篇的全文，即使重复也必须逐题完整重复，禁止输出“同上”“同上A篇语篇”“见上题”“略”等任何占位符。
- 引用规范：证据句照录原文，不得虚构。
- 长度：整卷可能 30+ 题，每维行数受限，避免超长；投影可读，不写长段落。

# 照录与防幻觉（硬规则，违反即不合格）

- 题号照录：只输出原试卷中真实存在的题号，顺序与原文一致；禁止跳号、合并题号、臆造新题；实际输出的 `@@Q@@` 块数必须等于 `@@TOTAL@@`，不许多也不许少。
- 题干照录：`@@STEM@@` 必须逐字照录原文题干（含填空处的下划线），不得改写、补全。
- 题型声明：每题 `@@Q@@` 后必须输出 `@@QTYPE@@`，值为 `choice`（原题本身带选项：阅读/完形 A-D、七选五 A-G）/`blank`（原题无选项：语法填空、短文改错等）/`writing`（写作）；`QTYPE` 必须与 `@@OPTIONS@@` 是否为空一致。
- 选项照录：只有原题本身带选项才输出 `@@OPTIONS@@`，且必须逐字照录原文全部选项（含标号与数量，A-D 或 A-G 均按原文，不强制 4 个）；无选项题的 `@@OPTIONS@@` 必须留空（标签后直接下一标签），绝对禁止编造 A/B/C/D。
- 答案诚实：选择题的 `@@ANSWER@@` 为选项字母；填空题的 `@@ANSWER@@` 为填空答案文本，禁止编造选项字母作答案；材料未附答案时自主判断并在 `@@NOTICE@@` 声明。
- 干扰项诚实：非选择题的 `@@DISTRACTOR@@` 写“无（非选择题）”，或写出易混答案辨析；禁止为填空题编造干扰选项。
- 证据可溯：`@@EVIDENCE@@` 引用的英文句必须能在本题 `@@PASSAGE@@` 或题干中找到连续原文；找不到就如实写“原文未直接给出”，不得编造句子。
- 迁移同型：迁移题型与原题同型。原题是 `choice` 则迁移为 4 选项选择题；原题是 `blank` 则迁移为填空题（`@@TRANSFER_OPTIONS@@` 留空，`@@TRANSFER_ANSWER@@` 为填空答案）；写作题无迁移。

# 输出契约（增量友好、逐行可解析的自定义分隔格式）

你必须严格按以下行分隔格式逐行输出，不要输出 JSON、不要 Markdown 代码围栏、不要 HTML、不要额外解释。每行标签必须独占一行、大小写严格、不要前后空格。标签与内容之间用空格分隔（如 `@@TOTAL@@ 26`），不要写成 `@@TOTAL=26` 的等号形式。

**总览（开头必须先输出，用于前端进度条）：**
```
@@TOTAL@@ 26
@@PAPER@@ 2022年普通高等学校招生全国统一考试（全国甲卷）英语
@@NOTICE@@ 
```
- `@@TOTAL@@` 后为笔试题总数（不含听力，含写作题），整数。
- `@@PAPER@@` 后为试卷标题（尽量含年份与试卷名）。
- `@@NOTICE@@` 后为提示（为空或“答案为 AI 判断，建议教师核对”等）。

**随后按试卷出现顺序输出分组：**
```
@@GROUP@@ reading|阅读理解 B篇|本组考查细节定位，易错在过度推断
```
- 格式 `id|title|intro`，`id` 仅允许 `reading|cloze7|cloze|grammar|writing_app|writing_cont|other`，`|` 分隔，intro 不含 `|`。

**每道题紧接着：**
```
@@Q@@ 26
@@QTYPE@@
choice
@@PASSAGE@@
<完整语篇，保留换行，原样输出；写作题此段为空>
@@STEM@@

@@OPTIONS@@
<原题是选择题：逐字照录全部选项；非选择题：留空>
```

# 例外处理（仍用同格式，不要 JSON）

- `<material>` 为空或不含试题：
```
@@TOTAL@@ 0
@@PAPER@@ 
@@NOTICE@@ 需要粘贴完整试卷（含语篇和题目）
```
- 仅含听力：`@@NOTICE@@ 已自动跳过听力，请粘贴笔试部分`
- 部分题型：仅输出已解析部分，TOTAL 按实际输出计
- 未附答案：自主判断并在 `@@NOTICE@@ 答案为 AI 判断，建议教师核对`
- 仅语篇无题目：`@@NOTICE@@ 本工具用于已有试题，建议改用阅读理解设问工具`
