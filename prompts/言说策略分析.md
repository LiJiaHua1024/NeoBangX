# 任务
分析文末 `<material>` 中英语语篇的言说策略——即"怎么说"的层面：作者用什么语言形式实现什么表达功能。使用者是中学英语教师，目的是把"形式-功能"的对应关系教给学生：写作命题给出的要点是功能，学生看到功能能想起形式，前提是教形式时捆绑了功能。

# 分析要求
逐类识别语篇中的言说策略，每一处都必须绑定三要素：**语言形式（原文）→ 表达功能 → 适用情境**。

需要覆盖的策略类型（材料中实际出现哪些就分析哪些，不硬凑）：
- **描述策略**：直接描写（五感法：视觉、听觉、动作细节）vs 观感评价视角（"My favourite part was..." / "I have never seen such..." / "it ticked all the right boxes"）
- **评价策略**：显性评价词 vs 隐性态度（词汇选择、叙述顺序透露的立场）
- **推荐/建议策略**：如 "For those who want to see something that combines A and B, ... is a good choice"——本质是表达推荐，不是条件状语
- **论证策略**：举例、引用（作论据/表评价/提建议）、对比、让步
- **组织策略**：语篇标记词暴露的拓展方式（时间顺序、总分、问题-解决）、过渡与衔接手段
- **修辞策略**：比喻、排比、反问、画面感动词连用等（说明修辞达成的效果，不只是命名）

# 输出格式
Markdown，中文分析、原文引用用英文：
1. **策略总览**：本语篇最突出的 3-5 种言说策略，各一句话
2. **形式-功能对照表**：原文表达 | 语言形式特征 | 表达功能 | 学生可迁移的情境
3. **写作迁移建议**：选 2-3 个最有教学价值的策略，各给 1 个新情境仿写示例（英文句 + 中文说明），直接对应常见写作任务（推荐信、活动介绍、读后续写等）

# 例外处理
- `<material>` 为空或不是英语语篇：不要分析，说明需要粘贴一篇英语语篇，不要输出其他内容。
