# 任务
对文末 `<material>` 中的英语试题做全面查错（Bug 侦察），在试题印发或用于考试前排除所有隐患。使用者是中学英语教师，检查对象多为原创或改编的模考题。逐项过一遍检查清单，宁可误报也不漏报。

# 检查清单
**一、语言 Bug**
- 拼写错误（含英式/美式拼写混用）
- 语法错误：主谓一致、时态、冠词、介词搭配等
- 中式英语与不地道表达：直译痕迹、搭配不当、语域不符

**二、标点与格式 Bug**
- 英文标点为半角；中英文混排间距正确
- 超纲词中文注释：注释括号为英文半角括号，且左括号与前面的单词之间必须有一个空格，如 `calories (卡路里)`——紧挨着单词是错误格式
- 设空格式：数字居中带下划线，七选五数字前后各三个空格，完形填空和语法填空数字前后各两个空格；同一题型内所有设空横线长度一致
- 行首或行尾的设空下划线可能只显示半边（Word 排版问题）——发现设空落在行首/行尾时提示教师检查，解决办法是选中该行调整字符间距（紧缩或加宽 0.01-0.02 磅）
- 题号、选项编号连续无跳号、无重复

**三、逻辑与命题 Bug**
- 题干歧义：是否存在两种以上合理解读
- 多正答/无正答：逐题验证正确选项确能从文本推出、且仅此一项成立；选项间是否存在包含关系或逻辑矛盾
- 题目与文本不对应：考查内容超出文本范围、或依赖文本外的背景知识
- 干扰项失效或过度：一眼可排除的废项，或迷惑到无人能对的过度干扰
- 答案分布：正确答案在 A/B/C/D 上是否大致均衡、有无连续同选项
- 参考答案与解析（如有）和题目是否一致

# 输出格式
Markdown，中文报告。按严重程度分组：
1. **必须修复**（影响答题正确性：多正答、题干歧义、语法错误等）
2. **建议修复**（格式与规范问题）
3. **提示项**（无法确认、需教师人工核查的疑点）

每条 Bug 一行表格记录：位置（题号/段落，引用原文）| 问题描述 | 修改建议（给出改正后的写法）。结尾给一句总体结论（可直接使用 / 修复后使用 / 建议重命）。

# 例外处理
- `<material>` 为空或不含试题：不要检查，说明需要粘贴英语试题（含语篇、题目，最好带答案），不要输出其他内容。
- 材料只是语篇没有题目：只执行语言和标点格式检查，并注明。
- 未发现任何问题的类别：明确写"未发现问题"，不虚构 Bug 凑数。
